# 포켓몬 잡으러 가자! 🌿⚪

6살 아이가 혼자서도 할 수 있는 포켓몬 잡기 게임입니다.
한글을 읽어야 포켓몬을 잡을 수 있게 만들어, 놀면서 글자 공부가 되도록 했습니다.

## 어떻게 실행하나요

### 📱 폰 / 태블릿
아래 링크를 카톡으로 폰에 보낸 뒤 열면 바로 실행됩니다.

**https://claude.ai/code/artifact/c4300b66-18f3-4327-a998-db7345aa2a4f**

브라우저 메뉴에서 **"홈 화면에 추가"** 를 누르면 앱 아이콘처럼 생겨서
아이가 혼자 눌러 들어갈 수 있습니다.

### 💻 PC
`index.html` 을 더블클릭하면 끝입니다. 설치도, 인터넷도 필요 없습니다.

## 🖼 진짜 포켓몬 이미지 넣기

`sprites` 폴더에 이미지를 넣고 **`이미지넣기.bat`** 을 더블클릭하면,
그 포켓몬이 넣으신 이미지로 바뀝니다.

1. `sprites` 폴더를 엽니다
2. 이미지 파일 이름을 **포켓몬 이름**으로 바꿔 넣습니다 — `피카츄.png`, `꼬부기.png`
3. `이미지넣기.bat` 더블클릭
4. `index.html` 을 열어 확인

- 넣지 않은 포켓몬은 원래 그림 그대로 나옵니다. **한 마리만 넣어도 됩니다**
- 메가진화 그림도 됩니다 — `메가리자몽.png`, `메가거북왕.png`
- `png` `jpg` `webp` `gif` 를 쓸 수 있고, 한 장이 500KB 를 넘으면 건너뜁니다
- 이미지는 게임 파일 안에 통째로 박히므로 **폰 링크에서도 그대로 보입니다**
  (단, 폰 링크는 제가 다시 올려드려야 반영됩니다 — 말씀만 주세요)

## 게임 방법

1. **친구 고르기** — 꼬부기 · 파이리 · 피카츄 · 이상해씨 중 하나
2. **탐험** — 초록 풀숲🌿 을 걸으면 야생 포켓몬이 나옵니다
   (방향 버튼 / 방향키 / 지도를 손가락으로 밀기 — 셋 다 됩니다)
3. **배틀** — 💥공격 으로 상대 체력을 절반까지 줄이면 몬스터볼 잠금이 풀립니다
4. **한글 퀴즈** — 이름을 소리로 들려주고, 첫 글자를 찾으면 **무조건 포획 성공**
5. **도감** — 포켓몬을 누르면 이름을 읽어주고, 진화 라인을 보여줍니다

## 진화

**키워서 진화** — 같이 다니는 친구는 포켓몬을 잡을 때마다 레벨이 1씩 오릅니다.
정해진 레벨이 되면 화면 가득 연출과 함께 진화합니다.

```
꼬부기 ─Lv.5→ 어니부기 ─Lv.10→ 거북왕 ─Lv.15→ ✨메가거북왕
```

**바로 잡기** — 야생에서 거북왕을 만나 바로 잡는 것도 됩니다.

**친구 바꾸기** — 도감에서 잡은 포켓몬을 누르고 `🤝 같이 가기` 를 누르면
그 아이와 함께 다니게 됩니다. 각자 키운 레벨은 그대로 유지됩니다.

**메가진화** — 최종 진화체를 **Lv.15** 까지 키우면 배틀 화면에
`✨ 메가진화! ✨` 버튼이 뜹니다. 그 배틀 동안만 강해집니다.
이상해꽃 · 리자몽 · 거북왕 · 팬텀 · 갸라도스 · 프테라 · 뮤츠 가 가능합니다.

## 한글 난이도가 자동으로 올라갑니다

| 잡은 수 | 문제 |
|---|---|
| 0~4마리 | 첫 글자 찾기 (보기 3개, 자음은 같고 **모음만** 다름) |
| 5~12마리 | 첫 글자 찾기 (보기 4개, 자음·모음·받침이 섞임) |
| 13마리~ | 이름 전체를 **순서대로** 조립하기 |

## 아이가 울지 않게 만든 규칙

- **게임 오버가 없습니다.** 체력이 0이 되면 "잠깐 쉬자!" 하고 저절로 가득 찹니다
- **틀려도 벌이 없습니다.** 퀴즈는 몇 번이든 다시 고를 수 있고,
  두 번 틀리면 정답 글자가 통통 튀며 알려줍니다
- **도망은 언제나 가능합니다**

## 어른용

- 시작 화면에서 **`▶ 이어서`** 와 **`🆕 새로 시작`** 을 고를 수 있습니다

- 오른쪽 위 🔊 버튼으로 음성·효과음을 끕니다
- 진행 상황은 자동 저장됩니다
