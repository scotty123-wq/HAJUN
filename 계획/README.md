# 작업 계획 문서

하준이 포켓몬 게임 업그레이드 작업의 지시서 모음입니다.
클로드에게 "계획 폴더 읽고 이어서 해줘" 라고 하면 여기서 이어받을 수 있습니다.

- `00-READ-FIRST.md` — 공통 규칙, 게임 철학, 금지사항 (**항상 먼저 읽을 것**)
- `spec-quiz.md` — 3차 퀴즈 15종 (완료)
- `spec-moves.md` — 4차 기술·이펙트·메가 (완료)
- `spec-evolve.md` — 5차 진화 선택·보너스 별 (완료)
- `spec-balance.md` — 6차 밸런스·포획 흔들림·쓰러짐/교체·데덴네
- `spec-map.md` — 7차 맵 4지역 확장 + 아이템
- `spec-fx.md` — 8차 이펙트 강화
- `spec-music.md` — 9차 배경음악

## 아직 안 한 것
- 6차 밸런스·데덴네 (작업 중이었음)
- 7차 맵 확장 + 아이템 ← **아빠 우선순위 1위 ("맵이 너무 작아")**
- 8차 이펙트 강화 / 9차 배경음악
- 10차 연타 전투 (내 차례 안에 연타한 만큼 추가 타격, 최대 5회)
- 11차 손가락으로 글씨 쓰기 (획순 학습)
