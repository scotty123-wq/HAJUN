# 7차 명세 — 배경음악 (평상시 / 전투)

아빠 요구사항:
> "평상시에 음악이 전투시에는 급박한 전투느낌 음악 추가하는것도 좋을것같아"

## 방식 — 음악 파일 금지
이 게임은 `index.html` 한 파일에 전부 박아 폰으로 서비스합니다(현재 1.6MB).
음악 파일을 base64 로 넣으면 수 MB 가 늘어 폰에서 느려집니다.
**기존 `SFX`/`tone()` 처럼 WebAudio 오실레이터로 멜로디를 연주하세요. 용량 0.**
- 이미 있는 `ac()` (AudioContext 생성/재개) 를 재사용
- 간단한 시퀀서: 음표 배열 + 박자 → 오실레이터. 8비트 게임음악 느낌
- 화음/베이스 한 줄 정도 깔면 훨씬 그럴듯해짐

## 곡 구성
- **평상시(필드·도감·타이틀)** — 밝고 편안한 느낌. 느린 템포. 산책하는 기분
- **전투** — 급박하고 신나는 느낌. 빠른 템포. 무섭지 않게 (6살)
- **쓰러짐** — 잠깐 가라앉는 짧은 곡 (6차에서 쓰러짐 상태가 추가됨)
- 화면 전환 시 자연스럽게 교체 (뚝 끊기지 않게 짧은 페이드)
- 루프. 너무 짧으면 지겨워지니 최소 8~16마디

## ⚠️ 반드시 지킬 것 — 목소리가 음악에 묻히면 안 됨
이 게임은 **포켓몬 이름을 읽어주는 한글 학습 게임**입니다. 목소리가 핵심입니다.
- 음악 기본 볼륨을 **효과음보다 확실히 낮게**
- `say()` 가 실행되는 동안 **음악 볼륨을 자동으로 더 낮추고(더킹), 끝나면 복구**
  (`speechSynthesis` 의 `onstart`/`onend` 활용)
- 효과음(`SFX.*`)과도 겹쳐 시끄럽지 않게

## 켜고 끄기
- 기존 🔊 버튼(`case 'mute'`, `S.voice`)이 음악까지 함께 제어
- **음악만 따로 끄는 방법도 있으면 좋음** (부모가 음악은 끄고 목소리는 켜고 싶을 수 있음).
  상단바가 좁으면 도감 화면 등에 배치. 상태는 저장(`save()`/`load()` 하위호환 필수)
- iOS 는 사용자 제스처 없이 소리를 못 냅니다. **첫 탭에서 시작**되게 할 것
  (`ac()` 가 `act()` 첫 줄에서 불리므로 그 흐름을 활용)
- 탭이 백그라운드로 가면 음악 정지 (배터리)

## 절대 지킬 것
- 1~6차 코드 훼손 금지 (`SFX` `tone` `say` `ac` 는 확장만 하고 기존 동작 유지)
- 저장 하위호환 유지
- 성능: 오실레이터를 너무 많이 동시에 쓰지 말 것 (저사양 폰)
