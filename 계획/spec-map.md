# 7차 명세 — 맵 확장 + 아이템 (우선순위 상향)

아빠 요청 (우선순위를 이걸로 올림):
> "맵이 너무 작아 ㅜㅜ"
> "맵이 확장(커지는것도 오케이 뭔가 넘어가는것도 오케이 아이템 등)"

현재: `MAP` 9×9 한 장 고정. `BLOCKED = [2,3]`. 이동은 방향버튼/방향키/스와이프.
야생 조우는 풀숲(타일 1)에서 24% 확률. 60마리가 **아무 데서나 똑같이** 나옴.

## 1. 지역 여러 개 (핵심)
9×9 한 장 → **지역 4개**로 확장. 지역마다 분위기와 나오는 포켓몬이 다름.

| 지역 | 분위기 | 나오는 타입 |
|---|---|---|
| 🌿 풀숲 | 지금 지역, 시작점 | 벌레·풀·노말·비행 |
| 💧 물가 | 물·모래 | 물·얼음 |
| 🕳 동굴 | 어둡고 바위 | 바위·땅·독·고스트·격투 |
| 🔥 산꼭대기 | 화산·정상 | 불·드래곤·전기·초·전설 |

- **지역마다 다른 포켓몬**이 핵심입니다. 지금은 탐험할 이유가 없습니다.
  "물 포켓몬 잡으러 물가 가자" 가 되어야 합니다
- 뒤쪽 지역일수록 센 포켓몬 → 3차 난이도 연동(`foeTough`)과 자연스럽게 맞물림
- 지역 이동: 맵 가장자리에 **출구 타일**을 두고 밟으면 이동. 6살이 알아보게 화살표·색으로 표시
- 지역 이름과 현재 위치를 화면에 표시 (한글 읽기에도 도움)
- **지역별로 타일 그림·배경색이 확연히 달라야** 함 (`TILE_ART` 확장)

## 2. 지역 크기
"너무 작아" 라는 피드백이므로 **한 지역도 9×9보다 크게** 만드세요 (예: 12×12).
- 폰 화면에 다 안 들어가면 **플레이어를 따라 지도가 움직이게**(카메라) 하거나,
  칸을 작게 하되 **터치 이동 타깃이 최소 32px 이상**은 되게
- 6살이 길을 잃으면 안 됩니다. 현재 위치를 항상 알 수 있게 (미니맵이나 지역명 표시)
- 어느 방식이든 `360×640` / `375×812` 에서 **넘침 0** 이어야 함
- 하준이 폰은 갤럭시 S25+ 라 성능은 걱정 안 해도 됨

## 3. 진행 방식
- 처음부터 4지역을 다 열지, 순서대로 열지 결정하세요. **권장: 처음엔 풀숲만, 조건을 채우면 다음 지역 개방**
  (예: 5마리 잡으면 물가, 12마리면 동굴, 25마리면 산꼭대기)
  6살에게 "새 곳이 열렸다!" 는 큰 보상이고, 처음부터 다 열면 센 데 갔다가 헤맵니다
- 새 지역이 열리면 크게 축하 연출

## 4. 아이템
넓어진 맵에서 **돌아다니며 줍는** 재미를 만듭니다.
- 필드에 아이템 타일이 가끔 생기고, 밟으면 획득 (또는 풀숲에서 낮은 확률로)
- 가방(인벤토리) 화면에서 보고 사용. 도감처럼 별도 화면 또는 모달

| 아이템 | 효과 |
|---|---|
| 💊 회복약 | 체력 회복 |
| 🍬 이상한 사탕 | 파트너 레벨 +1 |
| ⭐ 좋은 볼 | 퀴즈에서 보기 하나를 지워줌 (또는 포획 탈출 확률 낮춤) |
| ❤️ 기운의 조각 | **쓰러진 포켓몬 부활** (6차에서 만든 쓰러짐 상태와 연결) |

- 6살이 관리할 수 있게 **종류를 늘리지 말 것.** 4종이 상한
- 아이템 개수는 숫자로 크게 보이게. 획득 시 소리와 연출
- **아이템이 없어도 게임이 막히면 안 됨** (부활은 퀴즈로도 가능해야 함 — 6차 참조)

## 5. 저장
지역·해금 상태·아이템·좌표를 저장. 형식이 크게 바뀌면 `SAVE_KEY` 버전을 올리세요
(아빠가 기존 데이터 소실을 허용했습니다).

## 절대 지킬 것
- `00-READ-FIRST.md` 의 공통 규칙과 게임 철학 전부
- 6살이 **길을 잃거나 막히면 안 됨.** 되돌아가는 길이 항상 명확해야 함
- 센 지역에서 쓰러져도 되돌릴 수 없는 손실 없음
- 1~6차 코드 훼손 금지 (특히 6차의 쓰러짐/교체/부활, 5차 진화·별)
- 이동 스와이프와 `#map{touch-action:none}` 유지 (페이지가 같이 밀리면 안 됨)

## 검증에 반드시 포함
- 4지역 전부 실제로 이동해서 진입/복귀되는지, 막다른 곳이 없는지
- 지역별로 의도한 타입의 포켓몬만 나오는지 (각 지역 1000회 조우 시뮬레이션, 분포 표로)
- 해금 조건이 실제로 동작하는지
- 아이템 4종 획득·사용이 전부 되는지, 기운의 조각으로 부활되는지
- `360×640` / `375×812` 전 화면 넘침 0, 이동 타깃 32px 이상
- 저장/불러오기 후 지역·좌표·아이템·해금 상태가 복원되는지
