# 4차 명세 — 기술 여러 개 + 기술별 이펙트 + 메가 대형 연출

아빠 요구사항 원문:
> "기술이 하나말고 여러개 있어도 좋을것같고 기술마다 뭔가 이펙트가 다르면 더 활용할것같아
>  예를들면 백만폴트하면 전기가 날아가고 물대포하면 물모양으로 대포가 쫙날라가고"
> "메가진화버튼이있더라고? 그럼 얘가 수시로 메가로 변신할수도있고 그냥거북왕상태로싸울수도있단건데
>  메가면 별도 큰 이펙트가 들어가면 더 실감될듯"

## 1. 기술 여러 개
- 현재: `MOVES` 에 타입당 기술 2개, `S.mvI` 로 번갈아 자동 사용. 버튼 1개(`💥 기술명`)
- 변경: **내 포켓몬이 기술 3개를 갖고, 아이가 골라서 쓴다**
  - 타입 기술 2개 + 노말 기술 1개(몸통박치기 등) = 3개
  - 배틀 화면에 **기술 버튼 3개**를 한 줄로. 각 버튼에 기술 이름 + 타입 이모지
  - 기술마다 **위력이 다름**. 위력을 별(⭐) 개수나 색으로 표시해서 6살도 "이게 더 세다"를 알게
  - 위력 차이는 크지 않게 (예: 4~6, 6~9, 3~5). 어떤 걸 골라도 이기게 — 잘못 골라서 지는 경험 금지
- **빗나감(miss) 금지.** 6살에게 헛손질은 좌절입니다. 항상 맞습니다
- 상대도 자기 타입 기술 중 랜덤으로 사용 (지금과 동일하게 유지)

## 2. 기술마다 다른 이펙트 — 핵심
현재 `shoot()` 은 이모지 하나가 날아가는 공통 연출. **기술별로 모양이 달라야** 합니다.
아빠가 든 예시를 반드시 구현:
- **백만볼트** — 번개가 지그재그로 갈라지며 날아감 (SVG polyline + 번쩍임)
- **물대포** — 물줄기가 대포처럼 쫙 뻗어나감 (가로로 늘어나는 물줄기)

나머지 기술도 각자 다르게. 최소 이 정도 구분:
- 줄기형(대포/방사) — 가로로 뻗는 빔
- 갈라짐형(번개) — 지그재그
- 다발형(잎날가르기·독침) — 작은 조각 여러 개가 흩어져 날아감
- 회전형(용의숨결·바람가르기) — 회전하며 날아감
- 근접형(몸통박치기·펀치) — 투사체 없이 내 포켓몬이 직접 돌진해서 부딪힘
- 반짝형(초·신비한힘) — 상대 위에 빛이 터짐

전부 **인라인 SVG + CSS 애니메이션**. 외부 파일·라이브러리 금지.
`transform`/`opacity` 위주로 (저사양 폰 대응).

## 3. 메가진화 대형 연출
현재 `doMega()` 는 `lock(3700)` 짜리 연출. 이걸 **일반 진화보다 확실히 크게**:
- 화면 흔들림 (screen shake)
- 보라색(`--mega:#B268E0`) 오라가 포켓몬을 감쌈
- 포켓몬이 커지는 느낌 (scale 변화)
- 메가 상태 동안 이름표/슬롯에 보라 오라 지속 표시 — "지금 메가다"가 계속 보이게
- 메가 상태에서 쓰는 기술은 이펙트가 더 크고 화려하게 (같은 기술이라도 배로)
- 무섭지 않게. 신나고 멋있게

## 절대 지킬 것
- 게임 오버 없음 — 체력 0이면 "잠깐 쉬자!" 자동 회복. 이 분기 유지
- 6살이 울면 안 된다. 빗나감·패배·벌 없음
- 한 턴 3초 이내. 연출 길어지면 `lock()` 값도 같이 늘릴 것
- 터치 타겟 44px 이상. 기술 버튼 3개 + 볼/회복/도망이 **360×640 에 스크롤 없이** 들어가야 함
  → 안 들어가면 기술 버튼을 2개로 줄이거나 배치를 재설계할 것. 넘치면 안 됨
- 3차 퀴즈 코드(`QUIZ_TYPES` `pickQuizType` `answerPick` `viewQuiz` `openQuiz` 등) 훼손 금지
- 1차 폰 안전(`env(safe-area)` `touch-action` `-webkit-touch-callout`) 훼손 금지
- `lock()` `busy()` `LOCKED_WHILE_BUSY` `adultGate()` `doCatch()` `S.catching` 훼손 금지
- 기존 저장 데이터 호환 (`save()` 화이트리스트 건드리지 말 것)
