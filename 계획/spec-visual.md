# 23차 — 맵·캐릭터·배틀 배경을 예쁘고 실감나게

> `99-이어받기.md` → `00-READ-FIRST.md` 먼저. 작성 2026-11-13.

## 아빠 원문
> "움직이는 것도 2D긴 하지만 좀 허접한 느낌도 들고, 좀 더 이쁘고 실감나는 배경과 캐릭이었음 좋겠는데"

## 지금 상태 (왜 허접해 보이나)
- 맵 칸(`viewField`, `.tile .t0~t5`, `TILE_ART`)이 **단색 네모 + 이모지/작은 SVG**. 칸 경계가 딱딱하게 보임.
- 트레이너(`kidSvg(look)`, 21-B 에서 옷 파라미터화)가 **정지 그림 하나** — 걸을 때 다리·방향 변화 없음.
- 포켓몬은 공식 일러스트라 예쁜데 배경·사람만 촌스러워서 더 튐(20차 로켓단 때와 같은 문제).
- 배틀 배경도 단순.

## 방향 — "그림책처럼 그린 2D" (독창적인 화풍)
⚠️ 특정 게임의 맵 타일·캐릭터·화면 구성을 **베끼지 말 것.** 포켓몬 공식 일러스트는 이미 쓰고 있으니,
배경과 사람은 **우리만의 화풍**으로: 부드러운 그라데이션, 둥근 형태, 은은한 그림자, 따뜻한 색.
외부 이미지 다운로드 금지 — 손으로 쓴 SVG/CSS/캔버스로 (용량 걱정은 안 해도 됨, 폰은 S25+).

### A. 맵
- 칸 사이 **자연스러운 경계**(풀↔흙↔물 가장자리 둥글게/섞이게 — 오토타일 또는 겹침 장식)
- 칸마다 **질감**(풀잎·흙알갱이·물결·돌 무늬), 같은 칸도 몇 가지 변형으로 반복 티 안 나게(좌표 해시로 고정 — 리렌더해도 안 바뀜)
- **살아 있는 연출**(CSS transform/opacity 위주): 풀숲 살랑, 물 반짝·물결, 동굴 반딧불/수정 반짝, 산꼭대기 용암/불씨, 구름 그림자 천천히 지나감
- 나무·바위는 **입체감**(밑동 그림자, 앞뒤 겹침 — 트레이너가 나무 뒤로 가면 가려지는 정도)
- 4지역(grass/water/cave/peak) 모두. 풀숲(포켓몬 나오는 칸)은 **한눈에 구분**되어야 함(학습 흐름상 중요)

### B. 트레이너
- **더 현실감 있게 다시 그리기** (아빠: "트레이너도 더 현실성 있게"): 지금의 단순 아이콘형 → 
  자연스러운 비율(머리 너무 크지 않게, 2.5~3등신), 머리카락 결·옷 주름·명암(빛 방향 하나로 통일), 얼굴 표정 디테일.
  포켓몬 공식 일러스트 옆에 서도 어색하지 않은 완성도. 여전히 귀엽고 친근하게(6살 남자아이 모험가).
  특정 게임 주인공 디자인을 베끼지 말 것. 21-B 옷 부위(모자·윗옷·가방)는 이 새 그림에 맞춰 다시 그려 연결.
- **걷기 애니메이션**: 다리·팔 흔들림 2~4프레임(SVG 부분 transform), 방향 4개(위·아래·왼쪽·오른쪽 — 최소 좌우 반전 + 뒷모습)
- 칸 이동이 **부드럽게 미끄러지듯**(transform transition), 발밑 그림자
- 21-B 코스튬(모자·옷·가방)이 **모든 방향·프레임에서** 그대로 보여야 함
- **함께 다니는 포켓몬이 뒤를 따라 걷기**(한 칸 뒤, 공식 스프라이트 작게 + 통통 튀기, 21-B 장식 포함) — 아이가 제일 좋아할 부분

### B2. 맵에서 움직일 때 (아빠 확인: "맵 움직일 때도 바꾸는 거지?" → 예)
- 한 칸씩 **뚝뚝 끊기지 않게**: 트레이너가 칸 사이를 걸어가는 동안 지도(카메라)도 **같이 부드럽게** 따라감
- 방향 버튼·방향키를 **누르고 있으면 멈칫거림 없이 연속으로 걷기**(걷기 프레임이 이어지게), 손가락으로 밀기도 같은 느낌
- 지도 가장자리·지역 이동(게이트) 때 화면이 튀지 않게 짧은 전환
- 걸음에 맞춰 풀숲을 지나가면 풀이 흔들리는 반응
- 이동 규칙·속도 체감은 지금과 비슷하게(너무 느려지면 6살이 답답해함)

### C. 배틀 배경
- 지역별 배경 그림(하늘 그라데이션 + 원경 + 땅), 양쪽 포켓몬 아래 **받침 원판 그림자**
- 로켓단 배틀(20차 연출)과 충돌 없게

## 절대 지킬 것
- 6살: 무섭지 않게(동굴도 아기자기). 깜빡임 과하지 않게.
- 지도 크기·칸 수·이동 규칙·충돌·풀숲 판정(`ENC_TILE`) 등 **게임 규칙은 그대로.** 그림과 연출만.
- 폰 4해상도 + 태블릿(21-D 확대 방식과 함께) 넘침 0, 손가락 밀어서 이동·방향키 그대로 동작.
- `game.html` 만 편집, build·git 금지. 1~22차 훼손 금지.
