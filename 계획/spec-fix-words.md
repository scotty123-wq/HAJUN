## 버그 ① 말도 안 되는 글자가 오답 보기로 나옵니다 ★ 이게 더 급합니다

### 원인 (`distCho`, game.html 약 2933줄)
```js
function distCho(ch,count){
  const d = decomp(ch);
  ...
  const c = comp(pick(EASY_CHO), d.jung, d.jong);   // ← 원래 받침을 그대로 둡니다
```
초성만 바꾸면서 **원래 글자의 받침을 그대로 붙입니다.**
받침이 흔한 것(ㄱ ㄴ ㄹ ㅁ ㅂ ㅇ)이면 괜찮지만,
**겹받침·드문 받침이면 세상에 없는 글자가 나옵니다.**

### 실측 — 낱말 990개로 돌린 결과
**이상한 글자 1,224가지**가 만들어집니다. 예:
```
닭 → 랅 찱 칽 잙 팕 핡 앍        볶 → 곢 혺 녺 톢 촊 콖 돆 몪 롞 졲 폮 옦
팥 → 핱 닽 탙 잩 챁 캍 랕        숯 → 쿷 훛 퉃 풏 뭋 춫 룿 눛 웇 줓 붗 둧 궃
젖 → 텆 엊 넞 멎 겆 렂 첮 섲 펒   빛 → 킻    흙 → 츩    앉 → 랁    삶 → 탊
많 → 탆    있 → 닜    훑 → 굹
```
`닭 → 맑/밝/낡/탉` 처럼 **진짜 있는 글자도 섞여 있습니다.**
그래서 "드문 받침 금지" 가 아니라 **"실제로 쓰이는 글자만 내보내기"** 로 고쳐야 합니다.

### 고치는 방법
1. **쓸 수 있는 글자 목록을 두고 거기서만 뽑으세요.**
   가장 확실한 방법 — `WORDS` 990개 + 포켓몬 이름 322개에 **실제로 등장하는 모든 음절**을
   모아 집합(`Set`)으로 만들고, 오답 보기는 **그 집합 안에서만** 만듭니다.
   ```
   // 예시 방향 (그대로 쓰지 말고 직접 설계하세요)
   const REAL_CH = new Set();  // WORDS + 포켓몬 이름의 모든 글자
   ```
   이러면 아이가 보는 모든 글자가 **게임 안에서 실제로 쓰이는 글자**가 됩니다.
2. 집합에서 조건에 맞는 글자를 못 찾으면 `FALLBACK_CH` 로 내려가되,
   `FALLBACK_CH` 자체도 실제 글자만 들어 있는지 확인하세요.
3. **`distCho` 만 문제가 아닐 수 있습니다.** `distJung` `distJong` `makeDistractors`
   `nameDistract` `distWord` 등 **보기를 만드는 모든 함수**를 같은 기준으로 점검하세요.
   (`distJung` 은 받침을 0 으로 지우고, `distJong` 은 안전한 받침 7개만 쓰므로 지금은 안전해 보입니다 —
    그래도 직접 돌려서 확인하세요)
4. 기존 `BAD_CH` (욕설 차단) 목록은 그대로 유지하세요.

### 검증
- 낱말 990개 + 포켓몬 322개의 **모든 글자**로 보기 생성 함수를 전부 돌려서
  **실제로 쓰이지 않는 글자가 0가지**임을 보고하세요 (지금은 1,224가지)
- 보기가 항상 정답 1개 + 오답 n개로 채워지는지 (막히면 안 됩니다)

## 버그 ② 그림과 낱말이 안 맞습니다

두 가지가 섞여 있습니다.

### ②-a 정답이 둘인 문제 (실측 0.3%)
같은 그림을 쓰는 낱말이 보기에 같이 들어옵니다. **둘 다 맞는데 하나만 정답 처리됩니다.**
```
🌰 보여주고   보기: 밤 / 뭐 / 잣      → 밤도 잣도 🌰
🚪 보여주고   보기: 문 / 방 / 벌      → 문도 방도 🚪
✏ 보여주고   보기: 쓱싹 / 깎다 / 연필 → 연필도 깎다도 ✏
🐢 보여주고   보기: 거북이 / 느리다     → 둘 다 🐢
```
**고치는 방법**: `nameDistract` 가 오답을 고를 때 **정답과 같은 그림을 쓰는 낱말을 빼세요.**
이건 한 줄이면 됩니다. **반드시 고치세요.**

### ②-b 그림이 낱말을 아예 안 나타냅니다
`WORDS` 의 이모지 짝이 잘못된 것들입니다. 확인된 예:
| 낱말 | 지금 그림 | 문제 |
|---|---|---|
| 목 | 🧣 | 목도리입니다. 목이 아닙니다 |
| 등 | 🔙 | "BACK" 화살표입니다 |
| 식구 | 🍚 | 밥입니다 |
| 살 | 🫧 | 거품입니다 |
| 두더지 | 🐀 | 쥐입니다 |
| 배(신체) | 🫃 | 임신한 사람입니다 |

**규모**: 24개 묶음 중 **22개에서 그림이 겹치고**, 겹치는 그림 109가지,
영향받는 낱말 **267개 / 990개**. 전체에서 3개 이상 겹치는 그림이 105가지:
```
🌾 (10) 쌀 들판 들녘 밭 논 갈대 짚 낫 훑다 훑어
🍽 (9)  밥상 식탁 접시 그릇 쟁반 식당 먹다 배고프다 꼬르륵
💧 (8)  침 물 이슬 녹다 흐르다 얕다 계곡물 새다
🚪 (8)  방 문 옷장 밖 열다 닫다 좁다 똑똑
❓ (8)  묻다 왜 뭐 누구 언제 어디 어떻게 몇
```

**고치는 방법 — 현실적으로 판단하세요**
- 이모지로는 표현이 안 되는 낱말이 많습니다 (`왜` `언제` `어떻게` `꼬르륵` `훑다`).
  **이건 이모지 잘못이 아니라, 그림 문제에 쓰면 안 되는 낱말입니다.**
- 그래서 **모든 이모지를 고치려 하지 마세요.** 대신:
  1. **명백히 틀린 짝을 고치세요** (목→🧣 같은 것). 위 표 + 직접 찾은 것
  2. **그림 문제(`H_NAME` 그림 보고 낱말 고르기)에 쓸 수 있는 낱말만 쓰게 하세요.**
     `WORDS` 항목에 "그림으로 낼 수 있음" 표시를 추가하거나,
     그림이 그 낱말 **하나만** 가리키는 경우로 제한하는 방식.
     추상어(`왜` `언제` `어떻게`)와 동작어(`훑다` `꼬르륵`)는 **글자 문제로만** 내세요
  3. 겹치는 그림 중 **쉽게 바꿀 수 있는 것은 바꾸세요** (두더지→🦫 등)

### 검증
- `H_NAME` 을 4000회 뽑아 **정답이 둘인 경우가 0회**임을 보고 (지금은 11회)
- 그림 문제로 나오는 낱말이 **전부 그림과 1:1 로 맞는지** 목록으로 보고
- 고친 이모지 짝 목록
