# 손가락으로 글씨 쓰기 — 획순 학습

## 아빠 요구
> "하준이가 글 쓸 때 웬만한 건 쓰는데, 우리가 쓰는 순서가 있잖아.
>  일반적으로 그걸 틀릴 경우가 많아서 손가락 글씨쓰기랑 결합해서 이걸 먼저 하고 싶어"

**핵심**: 하준이는 **글자 모양은 쓸 줄 압니다. 못 하는 건 순서(획순)입니다.**
따라서 이 기능의 목표는 **예쁘게 쓰기가 아니라 올바른 순서 익히기**입니다.
- 모양 판정은 **관대하게**. 삐뚤빼뚤해도 통과
- **순서와 방향만** 봅니다

## 1. 데이터 — 자모 24개면 충분합니다
한글 음절 11,172자의 획순 데이터를 다 만드는 건 불가능합니다. 대신:

> **자모 24개의 획순만 정규화 좌표(0~1)로 만들고,
>  음절 안에서 위치·크기를 변환(어파인)해 배치하면 모든 글자의 획순이 자동 생성됩니다.**

손으로 넣을 데이터는 **폴리라인 약 46개**뿐입니다.

```js
/* 각 획 = 정규화 점 배열. 예시 형식 */
const STROKES = {
  'ㄱ':[[[0.15,0.15],[0.85,0.15],[0.75,0.88]]],                  // 1획
  'ㄴ':[[[0.20,0.12],[0.20,0.85],[0.85,0.85]]],                  // 1획
  'ㄷ':[[[0.15,0.15],[0.85,0.15]], [[0.15,0.15],[0.15,0.85],[0.85,0.85]]],  // 2획
  'ㅏ':[[[0.42,0.06],[0.42,0.94]], [[0.42,0.48],[0.86,0.48]]],   // 2획
  'ㅗ':[[[0.50,0.10],[0.50,0.60]], [[0.06,0.60],[0.94,0.60]]],
  /* ... 나머지 자모. 겹모음(ㅘㅙㅚ…)·쌍자음(ㄲㄸ…)은 조각 조합으로 런타임 생성 */
};
```
- **교육부 필순 기준**으로 통일하세요 (`ㅁ` 은 3획 등, 교재마다 다른 것은 하나로 고정)
- 겹모음·쌍자음은 **기본 자모의 조합**으로 만드세요. 손입력 불필요

## 2. 음절 배치 — 6가지 유형
모음 방향과 받침 유무로 6가지뿐입니다.
```
① 가로모음 받침없음  ㅏㅐㅑㅒㅓㅔㅕㅖㅣ   [초성|중성]        가 너 미
② 세로모음 받침없음  ㅗㅛㅜㅠㅡ           [초성/중성]        고 두 크
③ 섞임모음 받침없음  ㅘㅙㅚㅝㅞㅟㅢ       [초성/(중성)]      과 위 의
④ 가로모음 받침있음  ①+받침               [초성|중성]/종성   간 넘 밀
⑤ 세로모음 받침있음  ②+받침               [초성/중성]/종성   공 물 국
⑥ 섞임모음 받침있음  ③+받침               [초성/(중성)]/종성 관 원
```
게임에 이미 있는 `decomp()` `comp()` 로 초·중·종성을 얻어 위 규칙으로 배치하세요.

## 3. 판정 — 관대하게, 순서만
한 획을 그었을 때 **세 가지만** 봅니다. **모양은 절대 안 봅니다.**
```js
const R_START = 0.28;   // 캔버스 크기 대비 (280px 캔버스면 약 78px 반경)
const R_END   = 0.32;
const DIR_MIN = 0.30;   // 방향 cos. 약 72도까지 허용

judgeStroke(그린획, 지금그려야할획):
  시작점이 멀면      → 'start'
  끝점이 멀면        → 'end'
  방향이 반대면      → 'dir'
  그 외              → 통과
```
- **순서는 자동으로 강제됩니다** — 지금 그려야 할 획의 템플릿하고만 비교하므로
- "위→아래", "왼→오른쪽" 방향만 맞으면 통과. **삐뚤빼뚤은 전부 정답**
- **`ㅇ` `ㅎ` 의 원**은 시작/끝이 같아 방향 판정이 무의미 →
  **"닫힌 궤적인가"만** 보세요 (시작·끝 거리가 반경의 60% 이내 + 중심 주위를 반 바퀴 이상).
  시계/반시계 방향은 **묻지 않습니다**
- 6살 손가락은 지터가 큽니다 → 입력 좌표를 **3점 이동평균**으로 부드럽게, 10px 미만 이동은 무시

## 4. 절대 막히지 않는 3단 안전망 (필수)
| 실패 | 반응 |
|---|---|
| 1회 | 획이 흐린 회색으로 남고 `"이쪽에서 시작해 볼까?"` + 시작점에 💫 반짝임 |
| 2회 | **유령 획 애니메이션** — 템플릿이 스스로 그려지는 걸 1.2초 보여줌 |
| 3회 | **무조건 통과.** 획을 자동으로 예쁘게 그려 주고 `"같이 그렸다! 잘했어!"` |

→ 못 그려서 갇히는 경우가 **구조적으로 없어야** 합니다.

## 5. 어디에 넣나 — 단계적으로

**1단계 (이번에 할 것)**
- 새 화면 `S.screen = 'write'`. 필드에 **`✏️ 글씨 쓰기`** 버튼 추가
- 대상: **자모 24개** + 쉬운 음절 (받침 없는 2글자 낱말 정도까지)
- 캔버스 1개 (`min(78vw, 280px)` 정사각), **`touch-action:none`** 필수
- 획 순서를 **번호와 화살표로 안내** (① 어디서 시작해 어디로)
- 성공하면 별 지급 + 폭죽. **배틀·포획과 완전히 분리** — 한 턴 3초 규칙에 영향 없음
- 지금 배우는 낱말(`S.learn` 단계)과 연동하면 더 좋습니다

**2단계 (다음에)**
- 받침 있는 글자, 낱말 전체 쓰기
- 포획 성공 후 가끔 `"✏️ 이름 써 볼래? (별 3개!)"` 를 **선택지로** 제안.
  **건너뛰기 버튼을 항상 크게** — 강제하면 안 됩니다

## 6. 절대 지킬 것
- `00-READ-FIRST.md` 공통 규칙 전부
- **6살이 울면 안 된다.** 못 그려도 반드시 통과, 갇히는 경로 0
- 모양을 지적하지 마세요. 순서만 부드럽게 안내

## 7. 검증
- 자모 24개 전부 그려서 통과되는지
- **일부러 순서를 틀리게** 그렸을 때 제대로 잡아주는지
- **일부러 삐뚤빼뚤하게** 그렸을 때 통과되는지 (관대함 확인)
- 3번 실패 시 반드시 통과되는지 (갇힘 없음)
- `ㅇ` `ㅎ` 원이 어느 방향으로 그려도 통과되는지
- 음절 조합 6유형이 올바르게 배치되는지
- 두 해상도 넘침 0, 터치 타겟 44px 이상
- 1~16차 기능 생존
