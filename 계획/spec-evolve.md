# 5차 명세 — 진화를 아이가 선택 + 보너스 별로 진화

아빠 요구사항 원문:
> "지금 자동진화 -> 버튼누르면 진화할수있게 애기가 선택할 수 있게 뭔가 효과도 더멋있게"
> "어려운 문제에 보너스를 줘서 보너스 모으면 진화가능이나 이런것도 좋을것같아"

## 1. 진화를 버튼으로
현재: `checkEvolve()` 가 포획 1500ms 뒤 자동 실행되어 레벨 되면 **강제 진화**.

변경:
- 조건이 되면 **자동으로 진화하지 않고** `✨ 진화할 수 있어!` 버튼을 띄운다
- 아이가 누를 때 진화 연출 실행
- **안 눌러도 된다.** 지금 모습이 좋으면 그대로 둘 수 있고, 버튼은 조건이 유지되는 동안 계속 남는다
- 버튼 위치: 필드 화면에 눈에 띄게 (도감 상세에도 있으면 좋음)
- 진화 가능 상태가 되면 소리·반짝임으로 알려준다 (놓치지 않게)
- 진화하면 파트너가 진화체로 바뀌고 레벨은 유지

## 2. 진화 연출을 더 멋있게
기존 `#evo` 연출을 강화. 단, **메가진화보다는 덜 화려해야 한다** (메가가 최상급이어야 함).
- 실루엣이 변하는 느낌, 빛이 차오르는 느낌
- 진화 전/후 이름을 순서대로 보여주기 (한글 읽기 학습에도 도움)
- 무섭지 않게. 신나게

## 3. 보너스 별
- 퀴즈를 맞히면 **난이도(`S.quiz.want`)만큼 별을 획득.** 어려운 문제를 풀면 더 많이 받음
- 별 개수를 상단바 등 **항상 보이는 곳에** 표시 (예: `⭐ 12`)
- 별을 모으면 **레벨과 무관하게 진화 가능.** 필요 별 개수는 15개 권장
  (평균 2~3별/포획이면 6~8마리쯤에 한 번 → 6살에게 적당한 간격)
- 별로 진화할 때는 별을 소모. 레벨 조건으로 진화할 때는 별을 안 씀
- 버튼에 어떤 조건으로 진화 가능한지 표시 (예: `✨ 진화! (레벨)` / `✨ 진화! (⭐15)`)
- 별이 부족하면 얼마나 더 모아야 하는지 보여주기 (`⭐ 12 / 15`)
- 틀려도 별을 잃지 않는다. 벌 없음 (게임 제1원칙)

## ⚠️ 저장 데이터 (주의 — 처음으로 save() 를 건드림)
`save()` 는 지금까지 화이트리스트였고 한 번도 안 건드렸습니다. 별을 저장해야 하니 이번엔 필드를 추가합니다.
- `save()` 에 `stars` 추가
- `load()` 에서 **반드시 하위호환** 처리: `S.stars = typeof d.stars === 'number' ? d.stars : 0;`
- 하준이 폰에는 이미 예전 형식 저장 파일이 있습니다. **그걸 넣고 로드해서 잡은 포켓몬이 그대로 살아있는지 반드시 검증**할 것
- `wipe()` 에도 `S.stars = 0` 추가

## 절대 지킬 것
- 게임 오버 없음, 벌 없음, 6살이 울면 안 된다
- 4차 기술·이펙트·메가 코드 훼손 금지:
  `MOVES` `moveSet` `myMove` `foeMove` `fireMove` `shoot` `boom` `fxAt` `centerOf`
  `fx-beam/bolt/frag/spin/dash/claw/spark/whip/rock/cloud/orb/punch` `fx-ring`
  `mega-charge` `mgring` `megatag` `MEGA_MS` `charge-me` `charge-foe`
  `viewBattle` `attack` `foeTurn` `heal` `run` `doMega` `endTurn` `TURN_MS` `T_SHOT`
- 3차 퀴즈 코드 훼손 금지: `QUIZ_TYPES` `QUIZ_BY_ID` `pickQuizType` `foeTough` `skillCap`
  `comfort` `wantNumber` `answerPick` `viewQuiz` `openQuiz` `hearQuiz` `SAFE_IDS`
- 1차 폰 안전 훼손 금지: `env(safe-area-inset-*)` `touch-action` `-webkit-touch-callout`
- 잠금 훼손 금지: `lock` `busy` `LOCKED_WHILE_BUSY` `adultGate` `doCatch` `S.catching`
- 새 버튼도 터치 타겟 44px 이상, `360×640` / `375×812` 에 스크롤 없이 들어갈 것
