# 22-B — 가이드를 점점 없애기 (숙련도 개선)

> `99-이어받기.md` → `00-READ-FIRST.md` → `spec-tablet.md`(A4) 먼저. 작성 2026-11-16. 22차 바로 다음에.

## 아빠 원문
> "지금은 쓸 때 무조건 가이드 보고 … 익숙해지면 가이드 없이 쓰고 필요할 때 가이드를 보도록 점차 업그레이드가 돼야 되지 않을까?
>  같은 글씨 처음엔 가이드, 점차 가이드 생략 혹은 점점 없어지거나"
> 하준이는 **태블릿 모드**로 하고 있음. 계획 설명에 "ㅇㅇㅇ" 승인.

## 왜 지금은 늘 가이드만 보이나 (21-A 의 한계)
1. 같은 음절이 다시 잘 안 나옴 — 잡는 포켓몬 이름마다 글자가 달라 매번 lv 0 에서 시작
2. 음절 단위로만 기억 — "가"를 잘 써도 "거"는 처음부터
3. 단계가 뚝 끊김 — 진한 가이드 → 바로 빈 칸
4. 폰은 늘 따라 쓰기 (21-A 에서 폰은 그대로 두기로 했던 것)

## 고칠 것
### 1. 가이드 4단계로 점점 흐리게
| 단계 | 화면 |
|---|---|
| G0 | 시범 + 진한 가이드 따라 쓰기 (지금 lv 0) |
| G1 | 시범 없이 **흐린** 가이드 (불투명도 ~35%) |
| G2 | **지금 쓸 획의 시작점·첫 부분만** 살짝 (나머지 빈 칸) |
| G3 | 빈 칸 (4초 멈추면 시작점+화살표 — 지금 lv 1) |
| 다 배움 | 지금 lv 2 — 가끔 복습 |
- 깨끗하게 쓰면(도움·실수 없음) 한 단계 위로, 실수하면 **한 단계만** 아래로(지금처럼 바로 0 으로 떨어지지 말 것).
  아이에게는 단계 변화가 벌처럼 보이지 않게(문구·소리 없음).
- `👀 보여줘` 는 어느 단계에서든 그 글자 시범을 다시 보여 줌(도움으로 기록 → 도장 1).

### 2. 자모 숙련도도 기억 → 처음 보는 글자도 출발 단계가 올라감
- 음절을 쓸 때 그 안의 자모(초·중·종, 겹자모는 조각까지)별로도 성공/실수를 기록 (`S.wrj`).
- 처음 보는 음절의 출발 단계 = 구성 자모 숙련도의 **최솟값** 기준(예: 아는 자모만이면 G1~G2 에서 시작, 모르는 자모가 하나라도 있으면 G0).
- 획 단위로도: 이미 익숙한 자모의 획은 흐리게, 처음인 자모의 획은 진하게 — 가능하면(어려우면 음절 단위로만).

### 3. 배운 글자 다시 꺼내기 (간격 복습)
- 잡을 때 글자 고르기(`cwPick`)·연습 화면 글자 고르기에 **복습 몫**: 대략 3번 중 1번은
  "전에 연습했고 아직 다 배우지 않은 글자" 중 오래된 것(간격: 몇 시간 → 1일 → 3일 …).
- 나머지는 지금처럼 포켓몬 이름 글자 / 골고루 섞기. 같은 글자가 너무 연달아 나오지 않게.

### 4. 폰에도 같은 단계 적용
- 21-A 에서 폰은 "늘 따라 쓰기"였던 것을 해제 — 폰·태블릿 같은 숙련도·같은 단계.
  (태블릿 전용인 것은 그대로: 펜 잠금, 원 방향 판정, 큰 화면.)
- 폰 화면 배치는 바꾸지 말 것(그리는 내용만 단계별로 달라짐).

### 5. 어른 설정
- "다 배운 글자 / 연습 중 글자" 목록에 단계(G0~G3) 표시, 자모별 숙련도 한 줄.

## 검증
- node: 단계 전이(깨끗→위, 실수→한 칸 아래), 자모 기반 출발 단계, 복습 몫 비율·간격, 저장 왕복
- 브라우저: 같은 글자를 여러 번 써서 G0→G3 화면 변화 스크린샷(태블릿 1232×770, 폰 360×640)
- 폰 4해상도 + 태블릿 2방향 넘침 0, 콘솔 에러 0. 1~22차 훼손 금지. `game.html` 만, build·git 금지.
