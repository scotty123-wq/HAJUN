# 로켓단 배틀 — 팀을 골라 여러 마리로 싸우기

## 요구 (하준이가 직접 낸 아이디어)
아빠 전달:
> "하준이가 로켓단이 나와서 싸우는게 있었으면 좋겠대.
>  로켓단과는 꼭 1대1보다는 내가 몬스터 골라서 몇대몇으로 싸우는 방식이 좋을듯?!"

**이 기능의 의미**: 지금까지 모은 포켓몬이 도감에만 쌓였습니다.
로켓단 배틀은 **모은 것을 실제로 쓰는 첫 기능**이라, 수집에 목적이 생깁니다.

## 1. 만남
- 필드를 걷다가 야생 조우와 **별개로** 낮은 확률로 등장 (또는 지역마다 정해진 자리)
- 등장 연출을 특별하게 — 야생 포켓몬과 확실히 다르게. 대사 한 줄 ("우리는 로켓단! 포켓몬을 내놔라!")
- **무섭지 않게.** 6살 기준으로 악당이되 우스꽝스럽고 귀엽게
- 로켓단 그림은 **인라인 SVG 로 직접 그리세요.** (게임에 `kidSvg()` 선례가 있습니다)
  포켓몬 스프라이트처럼 외부 이미지를 쓰지 마세요 — 준비된 그림이 없습니다
- 처음 만나는 시점은 아이가 포켓몬을 어느 정도 모은 뒤가 좋습니다 (예: 도감 8마리 이상)

## 2. 팀 고르기 (핵심)
- 배틀 전에 **내 포켓몬 중에서 아이가 직접 3마리를 고릅니다**
- 도감과 비슷한 화면. 잡은 포켓몬만, **쓰러진(`ko`) 애는 못 고름**
- 고른 순서가 출전 순서
- 성한 포켓몬이 3마리 미만이면 **있는 만큼만으로** 진행 (막히면 안 됨)
- 각자 레벨과 체력은 평소 그대로 (`S.mons[i].lv`, 체력은 이어짐 — 13차에서 체력이 전투 사이 유지됩니다)

## 3. 싸움 방식
- **N 대 N 순서 배틀.** 내 1번이 쓰러지면 2번이 나옴
- 상대 로켓단도 여러 마리 (아이 팀 수에 맞추거나 1마리 적게 — 아이가 유리하게)
- 상대 포켓몬은 **악·독 타입 위주**로 (로켓단답게). 아북크·또도가스·나옹 같은 것
- 기존 배틀 시스템(기술 3개·필살기·메가·막대 게이지)을 **그대로 재사용**하세요. 새로 만들지 마세요
- **몬스터볼은 못 던집니다** (남의 포켓몬이므로). 대신 그 자리에 다른 버튼
- 상대를 전부 쓰러뜨리면 승리

## 4. 지면 어떻게 되나 — 가장 중요
**절대 되돌릴 수 없는 손실이 있으면 안 됩니다.**
- 내 포켓몬이 전부 쓰러져도 **잡은 포켓몬·레벨·별·아이템 하나도 안 잃습니다**
- 진 뒤에는 "다음엔 이길 수 있어!" 정도로 격려하고 필드로 복귀
- 쓰러진 포켓몬은 기존 방식대로 부활(퀴즈 2문제 또는 기운의 조각)
- **언제든 도망칠 수 있어야** 합니다
- 다시 도전할 수 있어야 합니다

## 5. 보상
- 이기면 **별을 넉넉히** + 아이템 몇 개
- 아이가 "이겼다!" 를 확실히 느끼게 큰 축하 연출
- 반복해서 이겨도 보상이 나오되, 무한 파밍이 되지 않게 조절(하루 몇 번 등은 6살에게 복잡하니
  간단히 — 예: 이길 때마다 보상은 주되 등장 확률 자체가 낮음)

## 6. 학습과 연결 (이 게임의 목적)
포켓몬을 잡는 게 아니라서 퀴즈가 빠질 수 있는데, **그러면 학습이 사라집니다.**
- **필살기·메가진화 문제 게이트는 그대로 작동**하게 하세요 (12차 기능)
- 추가로: 로켓단전 **시작 전이나 중간에 문제 1~2개**를 넣어 맞히면 유리한 효과
  (예: 우리 팀 전체 체력 조금 회복, 첫 공격 강화)
- 문제가 부담되지 않게 `🔙 그냥 싸울래` 는 유지

## 절대 지킬 것
- `00-READ-FIRST.md` 공통 규칙 전부
- **6살이 울면 안 된다.** 져도 잃는 것 없음, 도망 가능, 재도전 가능
- 무섭지 않게 — 악당이지만 우스꽝스럽고 귀엽게
- 한 턴 3초 이내 유지
- `360×640` / `375×812` 넘침 0 (특히 **팀 고르기 화면**과 여러 마리 표시)
- 기존 배틀 코드 재사용. `MOVES` `FXM` `hpBar` `dmgPop` `canUlt` `doMega` `lock` 등 훼손 금지
- `SAVE_KEY` = `pokemon-catch-v2` 유지, 옛 저장도 열려야 함
- 1~14차 코드 훼손 금지

## 검증
- 팀 고르기 — 3마리 미만일 때, 쓰러진 애가 섞였을 때, 1마리뿐일 때 전부 정상 동작
- 순서 교체가 제대로 되는지, 전멸 시 손실 0인지
- 도망·재도전 가능한지
- 필살기·메가 게이트가 로켓단전에서도 작동하는지
- 승리 보상 지급
- 레이아웃 넘침 0
- 1~14차 기능 생존

# [갱신] 로켓단은 애니메이션 그대로 — 아빠 지시

> "로켓단이야 실제로 많이 봐서 원래 만화 자체에서도 무섭지 않았잖아 ㅋㅋ 현실감 살려도 돼"

앞의 "무섭지 않게 우스꽝스럽고 귀엽게" 는 **수위를 낮추라는 뜻이 아니라 원작 그대로 하면 된다**는 뜻입니다.
하준이가 만화를 봐서 로켓단을 알고 있으니, **알아볼 수 있게 만드는 게 훨씬 재밌습니다.**

## 3인조로 구성
- **무사시** (빨간 긴 머리) · **코지로** (파란 머리) · **나옹** (말하는 나옹)
- 셋이 같이 등장. 나옹이 말을 합니다 (원작 그대로 — 아이가 제일 좋아하는 부분)
- 인라인 SVG 로 그리세요. 특징만 잡아도 아이는 알아봅니다
  (무사시=빨강 머리, 코지로=파랑 머리, 옷의 큰 **R** 자, 나옹=이마 금화)

## 등장 연출
- **열기구**(나옹 얼굴 모양)를 타고 내려오는 연출이면 최고입니다
- 등장 대사 — 원작 모토 느낌으로. 한글 학습 게임이니 **읽어주고 화면에도 크게**
  예: `"나쁜 짓을 일삼는 우리는!"` `"로켓단의 무사시!"` `"코지로!"` `"나옹이라옹!"`
- 대사는 한 줄씩 순서대로 뜨게 (아이가 따라 읽을 수 있게)
- 길어지면 지루하니 **전체 3~4초 이내**, 건너뛰기 가능하게

## 로켓단이 졌을 때 — 원작의 명장면
- **"또 당했다~!"** 하면서 셋이 **하늘로 붕 날아가 별이 되어 반짝** (blast off)
- 이게 6살에게 제일 신나는 순간입니다. 크게 연출하세요
- 소리·반짝임·꽃가루 아끼지 마세요

## 아이가 졌을 때
- 로켓단이 웃으며 떠나는 정도. **놀리거나 겁주지 말 것**
- 예: `"이번엔 우리가 이겼다옹!"` 하고 사라짐
- **잃는 것은 없습니다.** 격려 문구와 함께 필드 복귀, 재도전 가능

## 상대 포켓몬
원작에 맞춰 **아북크 · 또도가스 · 나옹** 계열이 자연스럽습니다.
이미 도감에 있는 애들이라 그림도 준비돼 있습니다.
- 무사시 → 아북크 계열 / 코지로 → 또도가스 계열 / 나옹은 본인이 직접 싸워도 재밌습니다

앞 문서의 나머지 내용(팀 고르기, N대N, 져도 손실 없음, 필살기·메가 게이트 유지,
레이아웃·기능 훼손 금지)은 **그대로 유효**합니다.

# [정정] 이름은 한국 더빙판 기준 — 로사 · 로이 · 나옹

아빠 지적:
> "무사시 코지로가 뭐야? 난 로이 로사는 아는데"

**앞에서 쓴 `무사시` `코지로` 는 일본 원판 이름입니다. 잘못 적었습니다.**
하준이가 보는 것은 한국 더빙판이므로 **한국 이름을 써야 아이가 알아봅니다.**

| 캐릭터 | 잘못 쓴 이름 | **올바른 이름 (한국 더빙)** | 특징 |
|---|---|---|---|
| 빨간 긴 머리 | ~~무사시~~ | **로사** | 빨강/자주 긴 머리 |
| 파란 머리 | ~~코지로~~ | **로이** | 파란 머리 |
| 말하는 고양이 | — | **나옹** | 이마에 금화 |

앞 문서에서 `무사시` `코지로` 라고 적힌 곳은 **전부 `로사` `로이` 로 바꿔 읽으세요.**
상대 포켓몬 배정도 마찬가지 — 로사 → 아북크 계열 / 로이 → 또도가스 계열 / 나옹은 본인.

## 대사 작성 지침
모토를 넣되 **일본판 직역을 쓰지 마세요.** 정확한 더빙 대사를 확신할 수 없다면
**짧고 자연스러운 한국어**로 만드세요. 이 게임은 한글 학습용이라
**어색한 한국어가 화면에 뜨고 음성으로 읽히면 안 됩니다.**

권장: 짧게 3~4줄, 아이가 따라 읽을 수 있는 쉬운 문장. 예시 수준
```
"우리는 로켓단!"
"로사!"
"로이!"
"나옹이라옹!"
```
- 이름을 크게 보여주면 하준이가 **읽기 연습**도 됩니다
- 길면 지루하니 전체 3~4초, 건너뛰기 가능
