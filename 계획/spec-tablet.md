## 왜 하나 (아빠 원문 요약)
- 하준이는 이제 한글을 **잘 읽지만 쓸 때 획순을 자주 틀립니다.** 아빠가 고쳐 주다 보니 서로 스트레스.
- 폰은 손가락이라 연필 연습이 안 됩니다 → **아빠 갤럭시탭 S10+ 와 S펜**으로 연습시키려 합니다.
- "기존 폰버전은 놔두고, 시작할 때 **태블릿 모드** 누르는 게 있고, 태블릿 모드를 켰을 때는
  **무조건 잡을 때마다 획순 연습을 한 번은** 하게 하고 싶어" / "둘 다 나와도 되긴 해"
- 틀리는 패턴: **획 순서 · 방향 · 글자 안의 순서(초→중→종) · 특정 글자 — 전부**
- 엄마 고민: 처음에 가이드를 보여 줄까, 안 보여 줄까 → **글자마다 숙련도에 따라 가이드를 줄여 간다**(아래 A4)로 합의.
- 보상: 별은 애매 → **도장을 모아 코스튬을 고른다.** 코스튬은 **포켓몬과 트레이너 둘 다.**
- 폰↔태블릿 기록 연동: **서버 없이 QR/코드로 옮기기**.

## 이미 있는 것 (다시 만들지 말 것)
- 획순 엔진: 자모 24 + 조합 규칙(쌍자음·겹모음·겹받침) + 음절 배치 6유형 → **한글 11,172자 전부** 쓸 수 있음.
  `wrPut` `wrBoxes` `wrEndStroke` `wrPaint` `wrMount` `wrNewTarget` (약 9380~10300줄)
- 쓰기 판 두 곳: ✏️ 연습 화면(`S.wr`, `openWrite`) / 배틀 덮개(`S.wrb`, 19차 필살기·퀴즈).
- 포획: `doCatch` (약 9183줄). 어른 설정 ⚙️ 화면(`setOf()`, 약 4850줄 부근).
- 저장: `save()` / `load()` (약 3547줄), `SAVE_KEY = 'pokemon-catch-v2'`.

## 21-A. 태블릿 모드 + 펜 + 잡을 때 한 글자 + 숙련도별 가이드

### A1. 태블릿 모드 켜기
- 시작 화면에 `✏️ 태블릿 모드` 토글(켜짐 표시가 분명하게). 어른 설정에도 같은 스위치.
- **기기별 설정**이므로 게임 저장과 별도 키(예: `localStorage['hajun-device']`)에 둡니다 —
  21-C 에서 기록을 옮겨도 태블릿 모드가 폰으로 따라가면 안 됩니다.
- 켜면 `body.tab` 클래스. 화면 크기로 자동 판단하지 말 것(아빠가 고르게).
- 어른 설정 스위치 `잡을 때마다 글자 쓰기`: 태블릿 모드면 기본 켬, 폰에서도 켤 수 있음.

### A2. 펜 입력 (가장 중요 — 손바닥)
지금은 `pointerdown` 이 오면 무조건 새 획을 시작합니다. 6살은 손바닥을 화면에 대고 씁니다.
- 한 획 도중에는 **처음 잡은 pointerId 만** 따라갑니다. 다른 포인터의 down/move/up/leave 는 무시
  (지금 `pointerleave`/`pointercancel` 이 다른 손가락 때문에 획을 끊을 수 있음 — 확인하고 막기).
- 한 번이라도 `pointerType === 'pen'` 이 들어오면 그 뒤로는 **touch 포인터를 캔버스에서 무시**
  (펜 전용 잠금). 태블릿 모드가 아니면 지금처럼 손가락 허용.
- `getCoalescedEvents()` 가 있으면 사용해 선을 매끄럽게. 캔버스 `touch-action:none` 확인.
- S펜 버튼·호버는 무시. 펜으로 화면 다른 버튼 누르는 건 정상 동작해야 함.

### A3. 태블릿 화면
- 갤럭시탭 S10+ CSS 뷰포트 대략 **1232×770(가로) / 770×1232(세로)** 전후. 두 방향 모두.
- 쓰기 캔버스는 **짧은 변의 80% 정도까지** 크게. 깍두기 공책처럼 **십자 점선** 안내선.
- 쓰는 동안 글자 칸 구분: **지금 쓸 칸(초/중/종)만 밝게**, 나머지 칸은 흐리게 → "글자 안의 순서" 학습.
- 폰 화면(320×568 / 360×640 / 375×812 / 384×832)은 **바뀌면 안 됩니다.** 모든 CSS 는 `body.tab` 아래에.

### A4. 숙련도별 가이드 (엄마·아빠와 합의한 핵심)
글자(음절)마다 상태를 저장합니다: `S.wrm[ch] = {lv, ok, miss, t}`
| lv | 상태 | 쓰는 방식 |
|---|---|---|
| 0 | 처음·최근 틀림 | **시범**(획이 하나씩 그려짐, 약 2초) → 흐린 글자 위에 **따라 쓰기** (지금 방식) |
| 1 | 따라 쓰기 성공 | **가이드 없이 빈 칸.** 막히면(약 4초 멈춤) 다음 획 **시작점과 화살표만** 살짝 |
| 2 | 혼자 2번 성공 | "다 배운 글자" — 가끔 복습으로만 |
- 혼자 쓰다 틀리면 그 글자는 lv 0 으로. **아이에게는 벌처럼 보이면 안 됨** — 문구·소리 없이 조용히.
- 시범은 **펜을 대면 즉시 끝나고** 바로 쓸 수 있어야 함(기다리게 하지 말 것).
- 틀렸을 때 알림을 종류별로:
  - 순서 틀림: 쓴 획을 잠깐 빨갛게 → 사라짐, 맞는 획이 깜빡 "이거 먼저!"
  - **방향 틀림**(지금 판정이 없으면 추가): 시작점 초록 점 + 화살표 "여기서 시작!"
  - 같은 획 3번 막히면 그 획을 유령 손이 그려 줌 → 막힘 없음
- 어른 설정에 **"다 배운 글자 / 연습 중 글자"** 목록(자주 틀린 순).

### A5. 잡을 때마다 한 글자
- 스위치가 켜져 있으면, 퀴즈를 맞히고 **몬스터볼을 던지기 직전**에 쓰기 덮개(`S.wrb`, purpose 새로 하나)를 엽니다.
- 쓸 글자: **잡는 포켓몬 이름의 음절 중 하나** — "피카츄를 잡자! **피** 써 볼까?"
  - lv 0/1 인 글자를 우선, 최근 쓴 글자(`WR_RECENT`)는 피함.
  - 5번에 1번쯤은 포켓몬 이름에 없는 글자(받침 글자 등, 낱말 990개에서)를 섞어 **모든 글자를 골고루**.
- 다 쓰면 볼이 날아가서 **반드시 잡힘.** 덮개를 닫거나 중간에 그만두는 길이 있다면 그때도 손해 없이 잡히게.
- 로켓단·배틀 흐름(`rkChallenge` 등)과 19차 필살기 쓰기는 건드리지 말 것.

### A 검증
- 합성 이벤트로: 펜 획 도중 touch 포인터 down/up 이 와도 획이 안 끊기고, touch 획이 안 생김.
- 1232×770, 770×1232 에서 쓰기 화면·배틀·맵 넘침 0. **폰 4해상도 화면이 21차 전과 동일**.
- lv 0→1→2→(틀림)→0 전이를 node 로 확인. 콘솔 에러 0.
- ⚠️ 실제 S펜 입력은 아빠가 태블릿으로 확인해야 함 — 보고서에 "미검증"으로 적기.

## 21-B. 도장판 + 코스튬

- 글자 하나를 끝까지 쓰면 **"참 잘했어요" 도장 1개**, 도움 없이(시범·힌트 없이) 완벽하면 **2개**.
  잡을 때 쓰기·연습 화면·배틀 쓰기 모두 해당. **도장은 절대 줄지 않음.**
- 도장판 10칸(꽉 차면 넘치는 건 다음 판으로) → **코스튬 상자**: 3개 중 1개 고르기. 가끔(약 1/6) 반짝 희귀.
- 코스튬 두 종류 — **둘 다**:
  1. **포켓몬 장식**: 모자·리본·왕관·선글라스·망토·꽃 등. 함께 다니는 포켓몬 그림 위에 겹쳐 그림(맵·배틀·도감).
     공식 스프라이트(webp)라 위치가 제각각 → 그림 bbox 기준 **머리 쪽(위 20%) / 목(가운데)** 정도로 단순 배치,
     포켓몬별 미세 조정 표는 만들지 말 것(나중에 아빠가 이상한 것만 신고).
  2. **트레이너 옷**: 맵의 트레이너(약 2770줄 SVG) 모자·옷·가방 색/모양.
- 손으로 그린 SVG, **종류 × 색 조합으로 30개 이상**. 나중에 추가하기 쉬운 표 구조로.
- 옷장 화면: 얻은 코스튬 입히기/벗기기. 포켓몬마다 따로 입힐 수 있음.
- 도장판·옷장은 폰에서도 보이고 쓸 수 있음(320px 넘침 0).

## 21-C. 기록 옮기기 (서버 없이)

- 어른 설정에 `📤 기록 보내기` / `📥 기록 받기`.
- 보내기: 저장 데이터를 압축(`CompressionStream('deflate')` 가능하면) → base64url.
  **크기를 먼저 재 보고**: QR 한 장(바이너리 약 2.9KB)에 들어가면 QR 표시(인코더는 파일 안에 직접 — 외부 CDN 금지, 오프라인 동작),
  넘치면 `navigator.share` 로 텍스트 보내기(카톡으로 나에게) + 복사 버튼.
- 받기: `BarcodeDetector`(삼성 인터넷·크롬 안드로이드) 로 카메라 스캔, 없으면 붙여넣기 칸.
- 받을 때 **확인 한 번**("지금 기록을 바꿀까요? 포켓몬 ○마리 → ○마리") 후 덮어쓰기. 기기 설정(태블릿 모드)은 안 옮김.
- 잘못된 코드면 아무 일도 안 일어나고 "코드를 다시 확인해 주세요".

## 절대 지킬 것
- 6살이 울면 안 된다: 실패·손실·막힘 없음. 쓰기는 끝까지 쓰면 **반드시** 보상.
- 한국어 자연스럽게(`josa()` `josaRo()`, 수사). 로켓단은 로사·로이·나옹.
- 폰 화면 동작·모양 **변경 금지**(태블릿 모드 꺼짐 기준). 1~20차 훼손 금지.
- `game.html` 한 파일만 편집. `node build.js`·git 은 메인 에이전트만.
- 저장 형식이 바뀌어도 하위호환에 공들이지 말 것(아빠 결정: 날아가도 괜찮음). 단 `S.wrm`·도장·코스튬은 `save()`/`load()` 에 넣기.
