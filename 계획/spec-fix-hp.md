# 아빠가 플레이하며 발견한 3건 수정

## ① 숫자 문제에 낱말 이모지가 섞여 혼동 (버그 — 최우선)

**아빠 원문**
> "질문에 나무 동그라미2개 별 동그라미 나오고 왼쪽에서 3번째는 뭐야? 이런 문제가 있는데
>  나무가 갑자기 왜 나오지? 저 문제의 답은 동그라미부터 세어야 정답인데
>  나무가 있다보니 나도 나무부터 세야된다고 생각했어"

**원인**: `quizHead()` 가 `head:'expr'|'jong'|'clock'|'dots'|'row'` 에서
소재가 낱말이면 `<div class="qemoji">${s.emoji}</div>` 를 **세는 물건 바로 왼쪽에** 붙입니다.
`N_NTH`(몇 번째) 문제에서 낱말이 `나무🌳` 면 `🌳 🔵🔵⭐🔵` 가 되어 나무를 1번으로 셉니다.

**고칠 방향**
- **숫자 유형(`kind:'num'`)에서는 낱말 이모지를 세는 대상 옆에 두지 마세요.**
  학습적으로 도움이 없고 오해만 만듭니다
- 특히 세거나 순서를 묻는 유형(`N_NTH` `N_COUNT` `N_PAT` `N_DIFF` `N_SEQ`)은
  **세는 대상만 화면에 있어야** 합니다
- 야생 포켓몬을 보여줘야 한다면(잡으려는 동기 유지) 세는 줄과 **확실히 떨어진 위치**에
  작게 두고, 시각적으로 구분되게 하세요 (테두리·배경·간격)
- 한글 유형은 지금처럼 이모지를 보여줘도 됩니다 (낱말 뜻을 돕는 역할)
- **숫자 문제는 애초에 낱말 소재를 안 쓰는 것도 방법입니다** — `pickSubject` 에서
  `kind==='num'` 이면 포켓몬 소재로 고정하는 쪽이 가장 단순하고 안전합니다. 판단해서 택하세요

**검증**: `N_NTH` `N_COUNT` `N_PAT` `N_DIFF` `N_SEQ` 를 각 500회 생성해
**세는 대상 외의 그림·이모지가 같은 줄에 섞이지 않는지** 확인

## ② 회복약이 쓸모없음 — 체력이 전투마다 리셋됨

**아빠 원문**
> "아이템을 먹은 효과가 있으면 이번 전투에 에너지 감소한게 다음에도 영향이 있어야
>  물약의 효용성이 올라가지 않을까?"

**원인**: `doCatch()` 안에 `S.maxHp = pMaxHp(); S.hp = S.maxHp;`
→ **포켓몬을 잡을 때마다 체력이 가득 찹니다.** 그래서 💊회복약을 쓸 이유가 없습니다.

**고칠 방향**
- 포획 시 체력을 **전부 채우지 말 것**. 소폭만 회복하거나(예: 최대치의 20~30%) 그대로 두기
- 체력이 **전투 사이에 이어져야** 회복약에 가치가 생깁니다
- 레벨업으로 `maxHp` 가 오를 때는 **오른 만큼만** 더해주세요 (현재 체력 비율 유지)
- ⚠️ **게임 철학은 유지**: 체력 0 이면 쓰러짐 → 교체/부활(6차 기능). 게임 오버는 없습니다.
  체력이 이어진다고 해서 아이가 막히면 안 됩니다
- 다른 `S.hp = S.maxHp` 지점들도 점검하세요. **정당한 것만 남기세요**:
  - 부활·기운의조각 → 가득 (정당)
  - 파트너 교체 → 그 포켓몬의 체력 상태를 따름이 자연스러움
  - 메가진화 → 지금 가득 채우는데, 그대로 둘지 판단
  - 새 게임 → 가득 (정당)
- 회복약 회복량도 다시 보세요. 너무 적으면 여전히 안 쓰고, 너무 많으면 긴장이 사라집니다

**검증**: 전투 3회 연속 진행해서 체력이 이어지는지, 회복약을 쓰면 실제로 이득인지,
체력 0 → 쓰러짐 → 교체/부활 경로가 여전히 막히지 않는지

## ③ 기술 위력 차이가 눈에 안 보임 — 하트를 막대로

**아빠 원문**
> "필살기라고 하는데 에너지 다는게 그냥 기술이랑 비슷한듯?
>  하트를 한개 두개씩 에너지가 다니깐 좀 약간 그 기술별 비중 차이가 크게 반영 안되는듯
>  약간 막대그래프? 100% 느낌으로 가던지 어쨋든 좀 세분화할 수 있는 것도 좋을것같아"

**원인**: `hearts()` 가 체력을 하트 개수로 보여줍니다. 하트 한 칸이 커서
일반 기술(16)과 필살기(22)의 차이가 표시에 안 나타납니다.

**고칠 방향**
- 체력 표시를 **막대(게이지)** 로 바꾸세요. 남은 비율이 부드럽게 줄어들게
- **숫자도 같이** 보여주면 좋습니다 (`24 / 48`) — 6살에게 숫자 읽기 연습도 됩니다
- 피해를 입을 때 **줄어드는 애니메이션** + 그 턴에 깎인 양을 잠깐 띄우면
  ("-22") 필살기가 세다는 걸 눈으로 배웁니다
- 색 변화 — 많으면 초록, 절반이면 노랑, 적으면 빨강
- 내 쪽·상대 쪽 **둘 다** 적용
- 하트가 귀여워서 좋았다면 막대 위에 작은 하트 아이콘 하나를 곁들여도 됩니다
- 몬스터볼이 열리는 기준선(절반)이 막대에 보이면 아이가 이해하기 쉽습니다

**검증**: 일반 기술과 필살기를 각각 맞았을 때 막대 감소폭이 눈에 띄게 다른지,
`360×640` / `375×812` 에서 넘치지 않는지

## 절대 지킬 것
- `00-READ-FIRST.md` 공통 규칙 전부
- 6살이 울면 안 된다. 막힘·되돌릴 수 없는 손실 없음
- 1~11차 코드 훼손 금지 (맵4지역·아이템·밸런스·포획흔들림·쓰러짐·진화선택·별·퀴즈26종·
  필살기게이트·낱말사전·기술이펙트)
- `SAVE_KEY` = `pokemon-catch-v2` 유지, 옛 저장도 열려야 함

# [정정] ①번 항목 — 아빠 추가 설명

> "포켓몬 소재로 꼭 고정하지 않아도 돼. 숫자 문제도 좋은데
>  저건 나무가 포함인지 아닌지 애매하게 표현되어 있어서 그래"

**앞에서 "숫자 문제는 포켓몬 소재로 고정하는 게 가장 안전하다"고 적은 부분은 취소합니다.**
낱말 소재를 쓰는 것 자체는 좋습니다. **배치가 애매한 게 문제입니다.**

고칠 방향:
- 소재를 포켓몬으로 고정하지 마세요. 낱말도 계속 쓰되 **세는 대상과 확실히 분리**하세요
- 세거나 순서를 묻는 유형(`N_NTH` `N_COUNT` `N_PAT` `N_DIFF` `N_SEQ`)은
  **세는 줄 안에 다른 그림이 절대 섞이면 안 됩니다**
- 분리 방법 (조합해서 쓰세요)
  - 세는 줄을 **테두리 있는 상자**로 감싸 "이 안에 있는 것만 센다" 를 시각적으로 명확히
  - 낱말 이모지·포켓몬은 **줄 바깥, 위나 아래**에 두고 간격을 크게
  - 세는 줄의 배경색을 다르게
  - 세는 대상은 전부 같은 크기, 장식은 확실히 작게
- 한글 유형은 지금처럼 이모지를 옆에 둬도 됩니다 (낱말 뜻을 돕는 역할)

검증: 위 5개 유형을 각 500회 생성해 **세는 줄 안에 세는 대상 외의 요소가 0개**인지 확인.
그리고 실제 화면에서 "무엇을 세는지" 가 한눈에 명확한지 확인.
