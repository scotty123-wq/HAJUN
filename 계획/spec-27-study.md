## 27-A. 혼자 한 번 더 (같은 자리에서 바로 다시 쓰기)
교육적으로 "보고 따라 쓰기 → 가리고 혼자 쓰기(Look-Cover-Write-Check)" 를 한 번의 쓰기 안에서.

- 가이드를 보고 쓴 경우(그 글자의 단계가 **G0·G1·G2** 이거나, 쓰는 중에 도움을 받은 경우) 다 쓰고 나면 바로:
  **"이번엔 혼자 써 볼까? ✨"** → 같은 글자를 **빈 칸**(번호·가이드·흐린 글자 모두 없음)에 한 번 더.
- 혼자 쓰기에서 막히면 22-B 처럼 **그 획만** 가이드가 돌아옴(4초 멈춤 → 시작점·화살표, 실수 → 그 획 진하게). 막힘 없음.
- 보상·숙련도:
  - 혼자 쓰기를 깨끗하게 → **도장 +1 추가**(합계 최대 3) + 숙련도 한 단계 위(22-B 규칙과 합쳐서 한 번의 쓰기로 최대 2단계까지는 올리지 말고 1단계만 — 판단해서 정하고 보고)
  - 혼자 쓰기에서 실수 → 숙련도 변화 없음(이미 1차에서 반영), 도장은 1차 몫 그대로. **절대 손해 없음.**
- 어디서:
  - **필살기 쓰기(19차 배틀)**: 혼자 한 번 더 성공하면 **필살기 더 세게**(예: "혼자 썼다! 파워 업!") — 아빠가 말한 바로 그 장면
  - **잡을 때 쓰기(21-A)**: 혼자 쓰기까지 끝나면 볼 던지기. 혼자 쓰기 중 `🤝 같이 쓰기`/끝내기도 가능, 그래도 반드시 잡힘
  - **✏️ 연습 화면**: 항상
- 시간이 늘어나므로: G3·다 배운 글자는 1번만(지금처럼). 어른 설정 `혼자 한 번 더` [켜기(기본)/끄기].
- 화면: 1차 끝나면 쓴 글씨가 살짝 사라지며(가리는 연출) 빈 칸 등장 — 무엇을 하는지 6살이 바로 알게. 음성 안내도.

## 27-B. 공부 기능
### 1. 받아쓰기 모드 (✏️ 연습 화면에 탭 추가)
- 글자를 **보여 주지 않고 소리로만** 들려줌("'사과'의 '사'를 써 볼까?" / 낱말 그림 함께 가능) → 빈 칸에 쓰기.
- 숙련도 G2 이상인 글자 위주로 출제(모르는 글자로 받아쓰기 시키지 않기). 다시 듣기 🔊 버튼 크게.
- 틀린 글자를 쓰면(다른 음절) 판정: 획순 엔진이 "목표 글자"에 맞춰 판정하므로, **정답 글자를 살짝 보여 주며 같이 써 보기**로 자연스럽게 이어 감 — 벌 없음.
- 잡을 때 쓰기에도 가끔(다 배운 글자일 때) 받아쓰기 형태로 출제.

### 2. 낱말 쓰기
- 한 글자 대신 **낱말 전체**(2~3음절: 포켓몬 이름, 낱말 990개 중 쉬운 것)를 칸 여러 개에 차례로 쓰기.
- 각 음절은 그 음절의 숙련도 단계대로 가이드. 다 쓰면 낱말을 읽어 주고 그림/포켓몬 등장.
- 연습 화면 탭 + 잡을 때 쓰기에 가끔(포켓몬 이름이 2~3글자이고 대부분 익숙한 글자일 때 "이름 전체 쓰기" 도전 — 선택이 아니라 가끔 나오는 이벤트, 도장 보너스).
- 태블릿은 칸 크게, 폰은 한 번에 한 칸씩 크게 보여 주고 진행 표시.

### 3. 엄마·아빠 리포트 (어른 설정 안)
- 이번 주 / 오늘: 쓴 글자 수, 깨끗하게 쓴 비율, **새로 다 배운 글자**, 자주 틀린 글자 TOP, 자주 틀린 **종류**(순서·방향·글자 안 순서) 비율, 자모 숙련도 변화.
- 날짜별 막대(최근 7일, 간단한 SVG). 기록은 save 에 날짜별 요약으로(크기 작게 — 21-C QR 크기 고려, 최근 30일만).

### 4. 하루 목표 + 연속 기록
- 기본 "오늘 글자 5개 쓰기"(어른 설정에서 3/5/10). 맵 화면에 작은 진행 표시.
- 달성하면 축하 + 특별 도장/작은 선물(코스튬 상자 진행 보너스 정도). **못 해도 손해 없음**, 연속 기록이 끊겨도 벌 없이 "다시 시작!" — 6살이 울면 안 됨(연속 기록 숫자보다 "이번 주 n일 했어요" 같은 누적 표시 위주).
