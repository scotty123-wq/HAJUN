## 3-2. `치고마 → 우라오스`

```
치고마(891) → 우라오스(892)
                 └─ 변종: 거다이 우라오스 (폼ID 10226)
```

- 우라오스만 넣고 치고마를 빼면 "진화형만 있는" 상태가 되므로 **반드시 치고마부터 등록**하세요.
- 거다이 우라오스는 진화 단계가 아니라 **우라오스의 변종**입니다. 진화 라인에 3단계로 넣지 마세요.
- 치고마·우라오스 둘 다 PokéAPI 상 `is_legendary: true` 입니다.

## 3-3. ⚠️ `우파` 는 두 갈래로 갈라지는 분기 진화

```
우파(194) ┬─ (일반)   → 누오(195)
          └─ (팔데아) → 토오(980)
```

- **토오를 누오의 진화형으로 연결하면 안 됩니다.**
- **토오의 진화 전 단계는 `누오` 가 아니라 `우파` 입니다.** (PokéAPI `evolves_from_species` = `wooper`)
- 따라서 `우파` 의 `evos` 배열에 **`누오` 와 `토오` 를 나란히** 넣어야 합니다.
  게임에 이미 이브이 8갈래 분기를 처리하는 `evos:[]` 구조가 있으므로 그대로 쓰면 됩니다.
- `누오` 와 `토오` 는 각자 `evos:[]` (빈 배열, 최종 진화).
- 화면 표현 참고: 분기의 팔데아 쪽 시작점을 `팔데아 우파`(폼ID 10253, 변종) 로 보여주면
  "우파가 팔데아에서는 다르게 생겼고 토오가 된다" 는 흐름이 아이에게 이해하기 쉽습니다.
  다만 **데이터상 토오의 부모는 어디까지나 `우파`** 입니다.

## 3-4. 변종은 진화가 아닙니다

거다이맥스 13개, 리전폼 22개, 코스튬 피카츄 3개, 기타 특수폼 10개 — **48개 전부 진화 관계가 아닙니다.**
각 변종은 `원종` 컬럼의 포켓몬에 **"다른 모습"** 으로 묶어서, 원종을 눌렀을 때 여러 버전이 보이는 방식으로 등록하세요.
진화 트리에 끼워 넣으면 라인이 망가집니다.

# 4. 등록 시 주의사항

## 4-1. 변종 파일명에 공백이 들어갑니다

- 기존 112개는 파일명에 공백이 없습니다. 이번 변종 48개는 **전부 `수식어 + 공백 + 종이름`** 형태입니다.
  예: `거다이 피카츄.webp` `알로라 라이츄.webp` `히스이 윈디.webp` `영물 랜드로스.webp` `팔데아 우파.webp`
- MONS 배열의 이름 문자열이 **파일명과 글자 하나까지 정확히 일치**해야 합니다 (공백 위치 포함).
- 이미지 경로를 URL로 조립한다면 공백 인코딩(`%20`)이 필요한지 확인하세요.
- 일반 60마리는 공백이 없습니다.

## 4-2. 강철 타입은 추가할 필요가 없습니다
