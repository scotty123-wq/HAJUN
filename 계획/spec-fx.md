# 이펙트 강화 명세

아빠 피드백 (실제 플레이 후):
> "그 효과이펙트는 다 잘들어갔는데 좀 더 멋있으면 좋겟음"

4차에서 넣은 기술 이펙트 12종(`fx-beam bolt frag spin dash claw spark whip rock cloud orb punch`)
이 정상 동작하는 것은 아빠가 확인했습니다. **한 단계 더 화려하게** 올리는 작업입니다.

## 올릴 방향
- **잔상/궤적** — 투사체가 지나간 자리에 흐릿한 꼬리가 남게
- **명중 순간 화면 흔들림** — 지금은 메가에만 있는 shake 를 강한 기술 명중에도 약하게
- **화면 섬광** — 강한 기술(⭐⭐⭐)은 명중 순간 화면이 살짝 번쩍
- **파편 개수·크기 증가** — frag 계열을 더 풍성하게
- **발광(glow)** — 타입 색이 번지는 느낌 (`filter: drop-shadow`)
- **충격 고리 강화** — 기존 `fx-ring` 을 이중 고리나 확장 링으로
- **기술별 개성 더 살리기** — 특히 아빠가 예로 든 백만볼트(갈라짐)와 물대포(줄기)를 가장 화려하게
- 메가 상태에서는 지금의 1.75배보다 더 극적으로

## 성능 — 걱정 안 해도 됩니다 (아빠 확인)
하준이 폰은 **갤럭시 S25+** 입니다. 고성능 게임도 도는 기기라 아빠가
"이펙트와 그래픽 고민은 너무 안 해도 된다" 고 명시했습니다.
- **화려함을 우선하세요.** 요소 개수·필터·글로우를 아끼지 마세요
- `transform`/`opacity`/`filter` 위주라는 원칙만 지키면 충분합니다
  (`width`/`top` 애니메이션은 여전히 피할 것 — 성능이 아니라 레이아웃 깨짐 때문)
- 다만 엄마 아이폰으로도 가끔 하므로, 동시 요소가 수백 개가 되는 극단은 피하세요
- 한 턴 3초 이내는 유지 (성능이 아니라 6살 집중력 때문). 늘어나면 `lock()` 도 함께 조정

## 절대 지킬 것
- 무섭지 않게. 6살이 놀라면 안 됨 (과한 붉은 섬광, 급격한 명멸 금지)
- 화면 흔들림이 심해서 멀미나면 안 됨 — 약하게
- 1~6차 코드 훼손 금지
- 360×640 / 375×812 에서 넘침 0 유지. `#fx` 는 `overflow:hidden`


## [갱신] 저장 호환 완화 + 성능 제약 해제
아빠 결정: "아예 새로운 게임 느낌이니 기존 데이터 날라가는건 괜찮아", 폰은 갤럭시 S25+.
- `save()`/`load()` 하위호환 검증에 시간 쓰지 말 것. 형식이 크게 바뀌면 `SAVE_KEY` 버전을 올려 옛 데이터를 무시
- 이펙트/그래픽 성능 걱정 불필요 — 화려하게
- 공통 규칙은 `00-READ-FIRST.md` 를 먼저 읽을 것

## [추가] 기술별로 달라야 함 — 타입별이 아니라 (아빠 피드백)
> "8차에 이펙트가 기술별로 다르게 들어갔으면 좋겟어
>  지금은 물기술이면 다 파란색 나가는느낌"

현재는 타입 색이 지배적이라 **같은 타입의 두 기술이 비슷해 보입니다.**
`물대포` 와 `거품광선` 이 확연히 달라 보여야 합니다.

기술마다 **모양·움직임·소리가 각자의 개성**을 갖게:
- `물대포` — 굵은 물줄기 하나가 대포처럼 직선으로 쫙
- `거품광선` — 크고 작은 거품이 통통 튀며 여러 개 흩어져 날아감
- `불꽃세례` — 작은 불씨가 여러 발 연속으로
- `화염방사` — 넓게 퍼지는 불줄기가 계속 뿜어짐
- `전기충격` — 짧게 탁 튀는 스파크
- `백만볼트` — 큰 번개가 지그재그로 갈라지며 화면까지 번쩍
- 나머지 기술도 같은 원칙으로 **하나하나 다르게**

색만 바꾸지 말고 **궤적·속도·개수·타이밍·소리**를 다르게 할 것.
같은 타입이라도 눈 감고 봐도 구분될 정도로.
