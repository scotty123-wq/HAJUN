## ⚠️ 코스모그·코스모움은 전설로 두지 말 것
API 상 전설이지만, `rare:2` 로 두면 **아이가 영영 못 만나서 솔가레오·루나아라로 진화시킬 수 없습니다.**
진화 전 2마리는 보통 확률로 나오게 하고, 최종형(솔가레오·루나아라)만 `rare:2` 로 하세요.

## 새 타입 2개 추가
게임에 **페어리, 악** 이 없습니다. 추가하세요.
- `TYPE_EMOJI` 에 항목 추가 — 페어리 🧚(또는 💗), 악 🌑(또는 😈)
- `MOVES` 에 기술 2개씩 + 이펙트
  - 페어리 — `요정의바람`(약) / `매지컬샤인`(강). 분홍 반짝이는 이펙트
  - 악 — `깨물어부수기`(약) / `나이트버스트`(강). 어두운 보라 이펙트
- 기존 12종 이펙트 중 비슷한 것을 재활용해도 되지만 **색과 모양은 구분되게**
- `ULT`(필살기)는 아직 없으므로 무시

## 이브이 8갈래 주의
`chainOf()` / `PREV` / `evo` 구조가 **분기(한 마리 → 여러 마리)** 를 지원하는지 확인하세요.
기존에 이브이 → 3갈래가 이미 있으므로 아마 되겠지만, 8갈래로 늘렸을 때
도감 진화 계보 화면이 깨지지 않는지 **반드시 실제로 열어서 확인**하세요.
너무 길어져서 화면을 넘치면 배치를 조정하세요 (가로 스크롤 또는 여러 줄).

## 검증
- `MONS` 총 **105마리**, 도감 `n / 105` 표시 정상
- 44마리 **전부 그림이 뜨는지** (파일명 불일치 시 SVG 대체 그림이 나오므로 반드시 눈으로 확인)
- 44마리 전부 야생 등장 가능, 퀴즈 소재로 출제 가능
- 페어리·악 기술이 실제로 발동하고 이펙트가 나오는지
- 진화 라인 8개가 도감 계보 화면에서 정상 표시
- 코스모그·코스모움이 보통 확률로 나오는지
- `360×640` / `375×812` 넘침 0 (특히 **도감 105칸**과 이브이 8갈래 계보)
- 1~6차 기능 전부 생존
