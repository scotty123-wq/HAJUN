# 6차 명세 — 밸런스 수정 + 쓰러짐/부활 + 데덴네 추가

아빠가 **직접 플레이하고** 준 피드백입니다. 실제 문제이니 최우선입니다.
> "나는 너무세고 상대방은 너무약한것같아 어느정도 밸런스가맞아야지
>  나는 에너지가 하나도 안달고 상대방은 너무 잘달어"
> "우리 포켓몬도 가끔은 죽기도하고(이건 아이템에 살릴수잇는걸 넣어노면 되지 않을까
>  혹은 문제 몇번 풀면 살릴수있다)"
> "혹시 데덴네를 추가할수있으면 해줘"

## 1. 밸런스 (원인 확인됨)
현재 상태 — 확인된 숫자:
- 내 피해량: `mv.p + rand(0~2) + floor(pLv()/2) + (megaOn?5:0)` → Lv1 7~9, Lv15메가 19~21
- 상대 피해량: `1 + rand(0~2)` → **1~3 고정. 강함도 레벨도 반영 안 됨 (설계 누락)**
- 내 최대체력: `12 + 내포켓몬hp + pLv()*2` → Lv1 28, Lv15 56
- 야생 체력: 9~26

결과: 내가 이기는 데 3~4턴 / 상대가 나를 쓰러뜨리는 데 **14턴(Lv15면 28턴)**.
전설 포켓몬도 잉어킹과 똑같이 1~3 을 때림.

### 수정
상대 피해량에 **그 포켓몬의 강함과 내 레벨**을 반영:
```
상대피해 = 2 + rand(0~2) + floor(foeTough(mi)) + floor(pLv()/3)
```
- `foeTough(mi)` 는 3차에서 만든 함수(0~8). 이미 있으니 재사용
- 잉어킹 2~4 / 뮤츠 7~9 / Lv15 에 센 놈 12~14
- 목표: 내가 3~4턴, 상대가 4~5턴 → 보통은 이기지만 긴장감 있음
- **실제로 시뮬레이션을 돌려 검증할 것** (아래 검증 항목 참고)
- 메가 상태면 상대 피해를 조금 줄여도 됨 (메가가 강해야 하니)

## 2. 쓰러짐 / 부활
현재: 체력 0 → 자동으로 가득 회복 + "잠깐 쉬자!" (게임 오버 없음)
**아빠가 이걸 바꾸자고 명시적으로 요청했습니다.** 지금까지 지켜온 원칙이지만 아빠 결정을 따릅니다.

변경:
- 체력 0 → `😵 쓰러졌다!` 상태 (**"죽었다" 라는 말은 쓰지 말 것.** 6살에게는 "기절/쓰러짐")
- 부활 방법: **퀴즈 2문제 연속 정답**
  - 부활 퀴즈는 **쉬운 난이도로 고정** (SAFE_IDS 또는 want=1~2). 쓰러진 상태에서 어려운 문제는 좌절
  - 틀려도 벌 없음. 몇 번이든 다시 풀 수 있음
  - 부활하면 체력 가득
- **절대 잃지 않는 것: 잡은 포켓몬(`S.dex`), 레벨(`S.mons`), 별(`S.stars`), 위치.** 진행도 손실 0
- 7차에서 아이템 "기운의 조각" 이 추가되면 그것으로도 부활 가능해질 예정. 지금은 퀴즈만
- 쓰러진 상태에서도 도감은 볼 수 있게 (아이가 갇힌 느낌 안 들게)

## 3. 데덴네 추가
- 그림은 **이미 `sprites\데덴네.webp` 에 넣어뒀습니다** (공식 일러스트 320px, 19KB). 다운로드 불필요
- `MONS` 배열에 추가. 타입 `'전기'` (게임에 페어리 타입이 없음)
- 진화 없는 단독 포켓몬 → 이브이·메타몽 같은 자리
- 체력은 작고 귀여운 포켓몬이니 12~14 정도
- `art` 속성도 채워야 함 (스프라이트가 없을 때의 대체 그림). 노란 몸 + 쥐 계열이니
  피카츄 계열 파라미터를 참고해 `form:'round'` 또는 `'biped'` + 노란색
- 도감 총 마리 수(`MONS.length`)가 자동으로 늘어나므로 "n/60" 표시가 깨지지 않는지 확인
- 전기 타입이라 4차의 전기충격/백만볼트를 그대로 사용 → 갈라지는 번개 이펙트 나옴

## 절대 지킬 것
- 6살이 울면 안 된다. 쓰러져도 **되돌릴 수 없는 손실은 절대 없음**
- 빗나감 없음, 틀려도 벌 없음
- 5차 진화/별 코드 훼손 금지 (진화 버튼, `S.stars`, `save()`/`load()` 하위호환)
- 4차 기술·이펙트·메가 훼손 금지:
  `MOVES` `moveSet` `myMove` `foeMove` `fireMove` `shoot` `boom` `fxAt` `centerOf`
  `fx-*` `mega-charge` `mgring` `megatag` `MEGA_MS` `charge-me` `charge-foe`
- 3차 퀴즈 훼손 금지: `QUIZ_TYPES` `QUIZ_BY_ID` `pickQuizType` `foeTough` `skillCap`
  `comfort` `wantNumber` `answerPick` `viewQuiz` `openQuiz` `hearQuiz` `SAFE_IDS`
- 1차 폰 안전 훼손 금지: `env(safe-area-inset-*)` `touch-action` `-webkit-touch-callout`
- 잠금 훼손 금지: `lock` `busy` `LOCKED_WHILE_BUSY` `adultGate` `doCatch` `S.catching`
- 저장 하위호환 유지 — 하준이 폰에 이미 저장 데이터가 있음

## 검증에 반드시 포함할 것
**배틀 시뮬레이션을 코드로 돌려 밸런스를 수치로 증명하세요.**
- 약/중/센/전설 포켓몬 × 내 레벨 1·5·10·15 조합으로 각 1000전
- 각 조합에서 ①내가 상대를 절반으로 줄이는 데 걸리는 평균 턴 ②상대가 나를 쓰러뜨리는 데 걸리는 평균 턴 ③내가 쓰러지는 비율
- 목표: 쓰러지는 비율이 **너무 높으면 안 됨**(6살이 좌절). 대략 10~25% 권장
- 이 수치를 표로 보고할 것

## 4. 포획 밸런스 (아빠 추가 피드백 — 실제 플레이 후)
> "밸런스에는 잡을때 밸런스도 가끔은 좀 못잡을수도있고? 뭔가 넘 다 쉽게잡히는 느낌"

현재: 퀴즈 정답 → `doCatch()` → **무조건 포획 성공**.

### 변경 — 정답을 벌하지 말고, 볼이 긴장감을 만들게
**절대 하지 말 것: 정답을 맞혔는데 랜덤으로 실패 처리.**
6살에게 "맞혔는데 왜 안 잡혀?" 는 학습 의욕을 꺾습니다. 정답은 항상 보상받아야 합니다.

대신 **몬스터볼 흔들림**으로 구현:
```
정답 → 볼 던짐 → 흔들 흔들 흔들 → ✨ 잡았다!
                               └→ 😮 앗, 나왔다! 다시 던져보자!
```
- 흔들림 횟수 1~3회, 매번 탈출 판정. 흔들릴 때마다 소리와 긴장감
- **탈출 확률은 `foeTough(mi)` 에 비례.** 잉어킹은 거의 안 나오고 뮤츠는 몇 번 나옴
  체력을 많이 깎아놨으면 확률이 낮아지게 해도 좋음 (배틀에 의미 부여)
- **탈출해도 야생 포켓몬은 도망가지 않는다.** 배틀 화면으로 돌아가 다시 볼을 던질 수 있음
  (퀴즈를 처음부터 다시 풀게 할지, 볼만 다시 던지게 할지는 구현하는 쪽 판단 —
   6살 기준으로 덜 지치는 쪽. 퀴즈를 매번 다시 풀게 하면 지겨울 수 있음)
- **연속 2~3회 탈출하면 다음은 반드시 성공.** 무한 반복 좌절 금지
  (`S.wild.escapes` 같은 카운터로 관리, 배틀 끝나면 초기화)
- 탈출은 **손실이 아니다.** 체력·별·진행도 아무것도 안 줄어듦
- 탈출 시 문구는 아쉽지만 밝게: "앗, 나왔다! 다시 해보자!" (혼내는 말투 금지)

### 검증 추가
- 약/중/센/전설 각 1000회 포획 시도 → 평균 시도 횟수와 최종 성공률(반드시 100%)을 표로
- 3회 연속 탈출이 발생하는지 (발생하면 보장 로직 버그)

## 5. 쓰러짐 처리 — 아빠 최종 결정 (위 2번을 이것으로 대체)
> "부활은 너가 말한게 낫겟다 다만 교체를 내가선택할수있게 도감이 뜨고
>  내가 교체할포켓몬을 그다음에 부활을 따로 선택할수있는?"

체력 0 → `😵 쓰러졌다!` → **아이가 두 가지 중에서 고른다**

### ① 교체 — 잡은 포켓몬 중에서 직접 선택
- **도감이 뜨고** 아이가 교체할 포켓몬을 **직접 고른다** (자동 선택 금지)
- 고르면 그 포켓몬이 파트너가 되어 배틀을 이어서 계속
- 각자 키운 레벨은 그대로 유지 (기존 `buddy` 기능과 같은 규칙)
- 쓰러진 포켓몬은 "쓰러짐" 표시가 남고, 부활시켜야 다시 쓸 수 있음
- 도감에서 **쓰러진 포켓몬은 고를 수 없게** 표시 (회색 등)

### ② 부활 — 쓰러진 포켓몬을 되살림
- 방법: **쉬운 퀴즈 2문제 연속 정답** (난이도 want 1~2 또는 SAFE_IDS 고정)
- 틀려도 벌 없음, 몇 번이든 재도전
- 부활하면 체력 가득
- 7차에서 아이템 "기운의 조각" 추가 시 그것으로도 부활 가능해질 예정

### ⚠️ 중요 — 교체할 포켓몬이 없는 경우
게임 초반에는 파트너 1마리뿐입니다. 이때 교체 선택지를 주면 막힙니다.
- **성한 포켓몬이 하나도 없으면 ① 교체를 아예 안 보여주고 ② 부활만 제시**
- 부활 퀴즈도 계속 틀리면? → **무한히 재도전 가능하게** 두고, 여러 번 틀리면
  보기를 줄이거나 정답을 반짝여서 반드시 넘어가게 (게임 제1원칙: 6살이 갇히면 안 됨)
- 어떤 경우에도 **막히거나 되돌릴 수 없는 손실이 생기면 안 됨**

### 상태 관리
- 쓰러진 상태를 `S.mons[i].ko = true` 같은 식으로 포켓몬별로 관리
- `save()`/`load()` 에 반영하되 **하위호환 필수** (기존 저장엔 `ko` 가 없음 → `undefined` 는 성한 것으로 취급)
- `wipe()` 에서 초기화
