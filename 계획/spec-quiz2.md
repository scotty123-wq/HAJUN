# 문제 확장 — 포켓몬에서 벗어나기 + 문제로 발동하는 특수행동

아빠 요구사항 원문:
> "문제가 너무 지금 포켓몬에 집중되있는것같아서 한글에 확장성에 한계가 잇는것같아
>  물론 더하기할때 지금 레벨에 몇 더하면 몇될까? 이런게 흥미를끌겟지만
>  한글이나 수학이나 어쩃든 교육이 나는 1순위이므로
>  지금 나온 포켓몬이랑 직접적인 연관이 안되는 문제를 내도 될것같아
>  다만 아이는 지금 문제를 풀면 내가 잡을수 있다니깐"
> "메가진화도 보니깐 계속하는게 아니라 내가 게임당 하려면 그떄그떄할수있더라고?
>  그럼 그때도 문제를풀고 공격도 하다가 필살기? 이런느낌은 문제풀면 할수있고 이런건 어떨까?"

## 1. 문제를 포켓몬에서 떼어내기 (핵심)
현재 3차 퀴즈 15종은 **전부 야생 포켓몬 이름**을 소재로 씁니다
(`H_FIRST_E` `H_LAST` `H_ORDER` 등이 `wm.n` 을 사용).
→ 60마리 이름을 다 외우면 한글 학습이 멈춥니다.

**변경: 문제 소재를 낱말 사전으로 확장.** 포켓몬 이름은 그중 하나가 됨.
- 기존 유형(첫글자/끝글자/받침/조립/빠진글자)은 **그대로 두고 소재만 갈아끼우면** 됩니다
- 동기부여는 유지: "이 문제를 풀면 잡을 수 있다" 는 그대로
- 야생 포켓몬 이름 문제도 **일정 비율은 남기기** (지금 만난 애 이름을 배우는 재미)
  권장 비율: 포켓몬 이름 4 : 일반 낱말 6

### 6살용 낱말 사전 (카테고리별로 넣을 것)
| 분류 | 예시 |
|---|---|
| 가족 | 엄마 아빠 할머니 할아버지 동생 누나 형 |
| 동물 | 강아지 고양이 토끼 사자 코끼리 기린 |
| 음식 | 밥 사과 우유 김밥 라면 바나나 딸기 |
| 색깔 | 빨강 노랑 파랑 초록 검정 하양 |
| 몸 | 손 발 눈 코 입 귀 머리 |
| 자연 | 해 달 별 나무 꽃 바다 산 비 |
| 탈것 | 자동차 버스 비행기 기차 자전거 |
| 일상 | 연필 책 가방 신발 모자 우산 |

- 낱말마다 **읽어줄 때 자연스럽게** (`say`) — 기존 TTS 흐름 그대로
- 그림이 필요한 유형(`H_PIC`)은 낱말엔 그림이 없으므로 **포켓몬 소재로 유지**하거나 이모지 사용
- 낱말은 2~3글자 위주 (6살 기준). 어려운 낱말 금지

### 수학도 확장
지금 7종(세기·비교·덧셈·뺄셈·레벨덧셈·빈칸·10넘는덧셈)에서 더:
- 순서 (첫째 둘째 셋째)
- 큰 수 / 작은 수 고르기
- 모양 (동그라미 세모 네모)
- **포켓몬 소재 문제도 유지** — "레벨이 3인데 2 올라가면?" 은 아빠가 흥미롭다고 한 유형

## 2. 문제로 발동하는 특수행동 (핵심)
지금은 **잡을 때만** 문제를 풉니다. 문제를 풀 기회를 늘려서 **많이 풀수록 강해지는** 구조로.

### ① 메가진화 게이트
- 메가진화 버튼을 누르면 **문제 1개**가 나오고, 맞히면 메가진화 발동
- 메가는 배틀당 한 번이라 특별한 순간 → 문제도 조금 어렵게 (난이도 3~4)
- 틀려도 벌 없음, 다시 풀 수 있음. 못 풀면 그냥 메가 안 하고 계속 싸우면 됨

### ② 필살기 (신규)
- 배틀에 `💥 필살기` 버튼 추가. 누르면 **문제 1개** → 맞히면 강력한 공격
- 일반 기술보다 훨씬 세고 이펙트도 화려하게
- 난이도는 중간(2~3). 자주 쓰는 거라 너무 어려우면 지침
- 배틀당 사용 횟수 제한 (예: 2회) 또는 쿨다운 — 남발 방지
- 필살기 이름은 타입별로 (예: 물 `하이드로펌프`, 불 `불대문자`, 전기 `번개`)

### 원칙
- **문제를 푸는 게 벌이 아니라 보상으로 느껴져야 함.** 강해지는 수단
- 틀려도 잃는 것 없음. 그냥 그 행동을 안 하면 됨
- 문제가 너무 자주 나와 지치지 않게 — 필살기 쿨다운으로 조절

## 절대 지킬 것
- `00-READ-FIRST.md` 공통 규칙 전부
- 3차 퀴즈 구조(`QUIZ_TYPES` `pickQuizType` `answerPick` `viewQuiz`)는 **재사용**.
  유형을 새로 만들지 말고 **소재(낱말)를 갈아끼우는 방식**이 훨씬 안전하고 싸다
- 5차 진화·별, 4차 기술·이펙트·메가 훼손 금지
- 6차 밸런스·포획 흔들림 훼손 금지
