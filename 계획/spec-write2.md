# 19차 — 획순 쓰기를 배틀에 녹이기 + 캔버스 확대 + 음절 중심

## 아빠 요구 (원문)
> "저건 내가 평상시에 싸울떄나 기술쓸대 나오지 않고 별도 화면이네
>  그럼 애가 저거하는거에 메리트를 못느끼지않을까?"
>
> "이게 화면이 조금은 작아져도 최대한키우고 다른걸 줄이더라도
>  글자를 쓰는거로 연습시키는게 현실감이 있을것같아 ㅈ만 쓰거나 이런거보다는"

두 가지입니다.
**① 쓰기가 게임 안에서 힘이 되어야 한다** — 별도 화면에만 있으면 아이가 안 한다.
**② 캔버스를 최대한 크게, 낱자(ㅈ) 말고 완성된 글자(음절)를 쓰게.**

---

## A. 쓰기를 배틀에 넣기 ★ 이번 차수의 핵심

### A-1. 필살기 = 글자 쓰기 (가장 중요)
지금 필살기(`canUlt` / `ultMove`)는 게이지가 차면 그냥 눌러서 씁니다.
여기에 **"글자를 쓰면 필살기가 나간다"** 를 넣으세요.

- 필살기 버튼을 누르면 → **배틀 화면 위에 쓰기 판이 뜸** (전체화면 전환 아님, 덮개)
- 글자 하나를 획순대로 쓰면 → **필살기 발동**, 기존 필살기 연출 그대로
- 이러면 아이 머릿속에 **"글씨 = 힘"** 이 박힙니다. 이게 목적입니다

**중요**: 못 써도 필살기는 나가야 합니다(3단 안전망 그대로).
다만 **잘 쓰면 더 세게**:
| 결과 | 효과 |
|---|---|
| 한 번에 성공 | 데미지 **2배** + ⭐+3 + "완벽하게 썼다!" 연출 |
| 도움 받고 성공 | 데미지 1.5배 + ⭐+1 |
| 3번 실패해서 통과 | 데미지 그대로 (벌 없음) |

### A-2. 배틀 퀴즈에 쓰기 유형 추가
`QUIZ_TYPES` 에 새 유형 `H_WRITE` 를 넣으세요.
- 보기 3개를 고르는 대신 **손가락으로 글자를 씁니다**
- 기존 퀴즈 뼈대(`openQuiz` / `answerPick`)를 최대한 재사용하되, `render:'write'` 로 분기
- **출제 빈도는 낮게** (`w` 가중치 낮게). 매번 쓰라고 하면 지칩니다.
  체감으로 **10문제에 1~2번** 정도
- `diff` 는 중간, `ns`/커리큘럼 단계는 기존 한글 단계에 맞추세요
- 성공하면 별 보너스

### A-3. 포획할 때 (선택 — 여유 있으면)
잡기 직전 "이름을 써 보자!" 로 첫 글자를 쓰게 하면 포획률 보너스.
**여유 없으면 건너뛰세요. A-1 이 우선입니다.**

### A-4. 연습 화면(✏️글씨)은 그대로 두되 보상 강화
지금은 별만 줍니다. **아이템도 주세요** (회복약/사탕 등 낮은 확률).
연습이 배틀에 도움이 된다는 게 보여야 합니다.

## B. 캔버스 최대한 크게

아빠: **"화면이 조금은 작아져도 최대한 키우고 다른걸 줄이더라도"**

현재 `min(78vw,280px)`. 384×832 에서 구성요소가 544px 쓰고 **178px 이 남습니다.**

### 이렇게 하세요
- 캔버스를 **`min(94vw, 400px)` 이상**으로. 남는 세로를 최대한 캔버스에 주세요
- 대신 줄일 것:
  | 지금 | 줄인 뒤 |
  |---|---|
  | `.wrmode` 48px | 40px 또는 캔버스 위 작은 토글로 |
  | `.wrhead` 76px | **한 줄로 압축** (큰 글자 + 낱말 + 획수를 가로 한 줄) |
  | `.wrhint` 22px | 캔버스 안 아래쪽에 **겹쳐서** 표시 (자리 차지 0) |
  | `.wrrow` 62px | 그대로 두되 버튼 높이만 살짝 |
- **가로도 키우세요.** 지금 `78vw` 는 폰 폭의 78%밖에 안 씁니다. `94vw` 로

### 세로가 모자라면
정사각형을 고집하지 말고 **가로폭 우선**으로 잡고 세로는 남는 만큼 주세요.
글자칸 비율은 정사각을 유지하되 캔버스 자체는 남는 공간을 다 먹어도 됩니다.

**검증**: 320×568(제일 작은 폰)에서도 넘침 0 이어야 합니다.
작은 폰은 캔버스가 작아지는 게 맞습니다 — 넘치는 것보다 낫습니다.

## C. 낱자 말고 음절 중심

아빠: **"ㅈ만 쓰거나 이런거보다는"**

지금 `가나다 한글` 모드는 낱자(ㄱ ㅏ …)와 음절(가 고 …)이 섞여 나옵니다.

### 이렇게 하세요
- **기본을 음절로.** 낱말에서 뽑은 진짜 글자를 쓰게 하세요
  (예: `「고기」 의 고`, `「바지」 의 바`) — 이미 그렇게 표시하고 있으니 비중만 바꾸면 됩니다
- **낱자는 크게 줄이세요.** 완전히 없애진 마세요 —
  그 음절에 **처음 나오는 자모**일 때만 워밍업으로 1회, 그 뒤엔 바로 음절
- 숫자 모드(`123`)는 지금대로 두세요
- 어른 설정(⚙️)에 **"낱자 연습 켜기/끄기"** 토글을 넣어 아빠가 정하게 하세요

1. **필살기 → 쓰기 → 발동** 한 바퀴를 브라우저에서 실제로 돌리고,

4. 음절 : 낱자 출제 비율 (500회 뽑아서)
5. 배틀 중 쓰기 판에서 **나가기가 항상 동작**하는지
6. 1~18차 생존 (도감 322, 로켓단 한 바퀴, ⚙️ 설정, 수학 문제)
