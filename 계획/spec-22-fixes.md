## A. 받침 획순 판정 강화 (가장 중요 — 21차 펜 쓰기와 직결)
- 현재 획순 판정 정확도 약 97.1%. 약한 곳은 **받침 칸**(칸이 작아서 허용오차·위치 판정이 빡빡하거나 헐거움).
- 목표: **맞게 쓴 획을 틀렸다고 하는 일(거짓 오답)을 0에 가깝게.** 6살에게 "맞게 썼는데 틀렸대"가 제일 해롭다.
  틀린 순서/방향은 여전히 잡아야 함(21-A 의 오류 종류별 안내가 동작해야 함).
- 방법은 자유. 예: 칸 크기에 비례한 허용오차 하한, 받침 칸 판정 시 시작·끝점 가중치, 이웃 칸으로 새는 획의 귀속 규칙.
- 측정: 정답 획에 사람 손떨림 같은 잡음(위치 ±, 길이 비율, 곡률)을 넣은 합성 획으로
  **받침 있는 음절 수백 개 × 여러 잡음 수준** — 수정 전/후 거짓 오답률, 순서·방향 오류 검출률을 표로.
  폰(작은 캔버스)과 태블릿(616px 전후) 크기 둘 다.

## B. 자잘한 화면 문제 (99-이어받기.md "알려진 자잘한 문제")
1. 배틀 버튼 4개가 360px 폭에서 각 77px 로 좁음 → 누르기 쉽게(최소 44px 높이·충분한 폭, 글자 안 잘리게)
2. 필살기 이펙트가 상단바를 살짝 덮음
3. 얕은물/깊은물 색 구분이 약함
4. "🔥 산꼭대기" 가 360px 에서 줄바꿈
5. `N_SUB` 가 답 0 을 만들 수 있음 → 6살 수준에 맞게 답 ≥ 1 (0 이 의도된 문제 유형이 아니라면)
6. 어른 설정(⚙️) 화면이 작은 폰(320×568)에서 세로 넘칠 가능성 — 21-A/B/C 카드가 늘었으니 꼭 확인
