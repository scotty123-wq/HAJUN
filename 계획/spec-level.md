# 난이도 조정(어른용) + 수학 내용 확장

## 아빠 요구
> "내가 레벨을 조정하는 부분도 좋을것같은데 지금 좀 쉽다고 느껴지긴해"
> "한글말고 수학적인것도 업데이트되면 좋고"

## A. 어른이 난이도를 직접 조정

**왜 필요한가**: 하준이 실력을 아는 건 아빠입니다. 자동 승급만으로는 실제 실력과 어긋날 수 있고,
지금은 **너무 쉽다고 느끼고 있습니다.**

### 만들 것 — 어른 설정 화면
- 진입 경로는 **아이가 실수로 못 들어가게.** 기존 `adultGate()`(덧셈 문제)를 재사용하세요
- 위치는 시작 화면 구석이나 도감 안쪽 등 아이 동선에서 벗어난 곳
- 조정 항목:
  | 항목 | 내용 |
  |---|---|
  | **한글 단계** | 1~6 직접 지정 (지금 몇 단계인지도 보여주기) |
  | **수학 단계** | 1~6 직접 지정 |
  | **전투 난이도** | 쉬움 / 보통 / 어려움 — `foeDamage` `wildMaxHp` 계수에 반영 |
  | **문제 난이도 보정** | -1 / 0 / +1 — `want` 에 더해지는 값 |
  | (선택) **약점 집중도** | `WEAK_SHARE` 조절 |
- **현재 학습 상태를 보여주세요** — 단계별 정답률, 최근 틀린 자모 등.
  아빠가 판단할 근거가 되고, 아이 성장을 보는 재미도 있습니다
- 조정값은 저장(`S.learn` 또는 별도 필드). 옛 저장도 열려야 함
- **되돌리기** 버튼 (자동으로 돌아가기)

### 지금 너무 쉬운 문제 — 함께 손보기
아빠가 "좀 쉽다"고 했습니다. 설정과 별개로 **기본값 자체를 조금 올리는 것**도 검토하세요.
- 승급 조건(현재 8문제 이상 & 70%)이 너무 헐거운지
- `skillCap()` 상한이 너무 낮은지
- 다만 **좌절 방지 장치(`comfort`)는 그대로 유지**하세요

## B. 수학 내용 확장

현재 수학 유형(세기·비교·덧셈·뺄셈·순서·몇번째·규칙·가르기·10만들기·시계·차이 등)에서 더 넓히세요.
6~8세 범위에서 아이가 재밌어할 것으로:
- **두 자리 수** 읽기·비교 (10~99)
- **10 단위 더하기** (20+30)
- **연속 더하기** (2+3+1)
- **곱셈의 씨앗** — 묶어 세기 (2개씩 3묶음은 몇 개?)
- **나누기의 씨앗** — 똑같이 나누기 (6개를 2명이 나누면?)
- **길이·크기 비교** (더 긴 것, 더 무거운 것)
- **돈 세기** (100원, 500원 — 실생활)
- **시계 30분 단위** (현재는 정시만)
- **홀수/짝수** 감각
- 그 외 판단해서 제안

각 유형은 **기존 뼈대(`head`/`render`/`judge`)를 재사용**하세요. 새 뼈대를 만들지 마세요.
난이도(`diff`)와 어울리는 단계(`ns`)를 붙여 커리큘럼에 자연스럽게 섞이게 하세요.

**포켓몬과 엮으면 더 좋습니다** — 아빠가 "레벨이 3인데 2 올라가면?" 같은 걸 좋아했습니다.
도감 수, 별 개수, 팀 포켓몬 수, 아이템 개수 등을 소재로 쓸 수 있습니다.

## 절대 지킬 것
- `00-READ-FIRST.md` 공통 규칙 전부
- **6살이 울면 안 된다.** 난이도를 올려도 좌절 방지 장치는 유지
- 어른 설정은 **아이가 실수로 못 건드리게**
- `game.html` 한 파일만. `node build.js`·git 금지
- `SAVE_KEY` = `pokemon-catch-v2` 유지, 옛 저장 호환
- 1~16차 훼손 금지

## 검증
- 어른 설정으로 바꾼 값이 실제 출제·전투에 반영되는지
- 아이가 우연히 들어갈 수 없는지
- 신규 수학 유형이 전부 정상 출제, 답이 음수·잘못된 값이 안 나오는지 (각 5000회)
- 두 해상도 넘침 0
- 옛 저장 정상 로드
- 1~16차 기능 생존
