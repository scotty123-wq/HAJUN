# 29차 — 쓰기 방식 단순하게: "① 순서 보며 쓰기 → ② 회색 글씨 위에 순서 기억해 쓰기"

> `99-이어받기.md` → `00-READ-FIRST.md` 먼저. 작성 2026-11-17. 22-B(G0~G3)·27-A(혼자 한 번 더)·28-B(위치 맞춤 판정)를 **이 방식으로 정리**.

## 아빠 원문 (태블릿 실사용 후)
> "획을 쓰는데 약간 애매하네…? 획순 잡을 때 **아직 안 썼는데 다음으로 넘어간 것**도 있고 좀 애매해.
>  우선 획순이 주요라서 두 번째 쓰는 가이드에 **백지는 아니고 그냥 그 회색 글씨 정도는**.
>  1번 — 순서 보여 주고 숫자로 표현돼 있음
>  2번 — 회색 가이드는 있되, 순서 보여 주는 거랑 숫자로 '획을 이렇게 먼저 써라'는 지운 거로 갈까 싶네. 우선 획 공부니까."

## 새 방식 (모든 쓰기: 연습 가나다·낱말, 잡을 때, 필살기)
| 단계 | 화면 | 목적 |
|---|---|---|
| **① 보며 쓰기** | 회색 글씨 + **획 번호** + 획순 시범(한 획씩, 21-D 속도 설정) + 지금 쓸 획 강조 | 순서를 보고 익힘 |
| **② 기억해 쓰기** | **회색 글씨만**(같은 진하기). 번호·시범·지금 쓸 획 강조·화살표 **없음** | 모양은 보이되 순서는 스스로 |
- 글자 하나 = ① → ② 두 번. 백지(빈 칸)는 **없음** (받아쓰기 탭은 원래 소리 듣고 쓰는 모드라 그대로 두되, 회색 글씨 없이 쓰는 건 그 탭에서만).
- ② 에서 순서·방향을 틀리면: 맞는 획에 **그 획 번호만** 잠깐 보여 주며 "이거 먼저! 👉" / 시작점 "여기서 시작! 🟢". 틀린 획은 지워짐. 막힘 없음.
- **익숙한 글자**(② 를 도움 없이 여러 번 맞힘 — 기준 정해서 보고)는 ① 을 건너뛰고 ② 만. 다시 틀리면 다음엔 ① 부터.
  → 22-B 의 G0~G3 단계·흐린 정도 변화·자모 숙련도로 출발 단계 정하기는 이 두 상태(배우는 중 / 익숙)로 단순화.
  저장 데이터는 이어서 쓰되(lv 매핑) 복잡한 단계 UI 는 정리. 어른 리포트·간격 복습(22-B)·도장(21-B)·하루 목표(27-B)는 유지.

## 버그: "아직 안 썼는데 다음으로 넘어감" — 꼭 원인 찾기
후보: 멈춰 있으면 유령 손이 대신 그리고 통과 처리(21-A: 3번 막히면 자동), 28-B 의 너그러운 판정(wrRough/구조 rescue)이
다른 획을 이 획으로 인정, 한 번 그은 선이 두 획으로 세어짐, 'tiny' 처리, 시범 중 터치, 타이머.
- **규칙: 하준이가 직접 긋지 않은 획은 절대 완료되면 안 됨.** 유일한 예외는 아이가 직접 `🤝 같이 쓰기` 를 누른 경우.
  자동 유령 손은 **보여 주기만** 하고 획을 채우지 않음.
- 한 번 그은 선은 최대 한 획으로만 인정.

## 판정 (회색 글씨가 늘 보이므로)
- 회색 글씨 위에 쓰므로 위치 기준은 다시 **글씨 자리 기준**(22차 수준 + 약간 여유). 28-B 의 "아이 위치에 맞추기"는
  거절된 획 구제용으로만(순서가 맞고 모양이 맞을 때). 순서·방향이 최우선(아빠: 획 공부).
- 같은 모양 획(ㅂ 세로 두 개, ㅅ 두 다리, ㄹ, ㅌ 등)의 **순서는 확실히** 잡을 것 — 회색 글씨 자리 기준이라 가능.

## 검증
- 버그 재현 → 원인 → 수정 후 재현 안 됨(합성 입력으로 재현 시나리오 제시)
- ①·② 화면 스크린샷(태블릿 1232×770, 폰 360×640), ② 에 번호·화살표·강조 없음 확인
- 순서·방향 검출률, 맞게 쓴 글자 거절률 표(28-B 벤치 재사용, 가이드 위 쓰기 기준)
- 모든 기존 스위트 통과(의도한 변경만 기대값 수정), 넘침 0, 콘솔 에러 0
